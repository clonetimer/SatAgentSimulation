## 4. IMU 可观测性结果

健康—故障对采用相同随机种子，因此故障前相同噪声序列可以严格对齐。此处的差分是**离线配对物理效应**，不是部署时可用的健康孪生残差，也不是检测器性能指标。

| 参考激励 | 噪声 σ | 故障前最大差异 | 故障后陀螺仪最大差异 |
|---|---:|---:|---:|
| 0° | 0 | 0 | 0 |
| 0° | 0.0001 rad/s | 0 | 0 |
| 0.9° | 0 | 0 | 4.09094×10⁻⁵ rad/s |
| 0.9° | 0.0001 rad/s | 0 | 4.09094×10⁻⁵ rad/s |

0.9° 条件下，故障—健康的最大差异分轴为：

- X：4.09094×10⁻⁵ rad/s
- Y：9.93948×10⁻⁶ rad/s
- Z：6.52462×10⁻⁶ rad/s

在噪声开启的健康 pulse09 运行中，传感器测量减去仿真角速度真值所得的 QA 残差标准差（30 个非初始样本）为：

| 轴 | 残差标准差 |
|---|---:|
| X | 1.378999×10⁻⁴ rad/s |
| Y | 1.000549×10⁻⁴ rad/s |
| Z | 9.913630×10⁻⁵ rad/s |

因此本轮观测到的故障物理效应小于所设噪声残差的样本标准差。这个比较提示传感器噪声可能掩蔽微弱效应，但**不能据此宣称检测失败或成功**：本 R0 没有使用独立噪声种子建立健康/故障分布，也没有计算误报率、检出率或检测延迟。QA 中的“IMU 减 simulator truth”只用于噪声核验，绝不进入推理特征。

## 5. 数据隔离与交付

证据包将以下内容分开保存：

1. \`r84_sensor_observations.json\`：仅时间戳与官方原始陀螺仪三轴值。
2. \`r84_case_manifest.json\`：实验臂条件、随机种子和事件回执。
3. \`r84_physics_qa.json\`：9 次运行的物理 QA 行、C++ 权限读回、R83m 对照、配对差异和噪声残差。
4. \`r84_execution_manifest.json\`：原始 ZIP/Wheel/协议/源代码和输出文件哈希。
5. \`source/r83m-original.zip\` 与 SHA-256 sidecar：被本次审计使用的 R83m 原始基线。

模型输入候选仅为 \`imu.raw_gyro_rad_s_x/y/z\`。故障标签、轮索引、故障时刻、hub 真值、C++ 权限、实际施加力矩和 \`QA_ONLY\` 字段均不在传感器观测文件中。

## 6. 结论与下一步

R84-R0 **证明了官方 Basilisk IMU 旁路测量链可以接入原生 FSW—RW 仿真，且在当前 8 个固定工况中没有改变原始物理链**。同时，0° 条件下故障在本观测通道中不可区分；0.9° 激励产生了可复现的微弱陀螺仪物理差异，但其幅值小于噪声残差标准差。

当前不训练、不构造正式训练/验证/测试集，也不宣称检测准确率。建议下一步先预注册 R84-R1：使用独立噪声种子和更多独立轮系/初始状态组，保留健康-only 误报控制与不可观测负例，评估信号分布重叠和噪声敏感性；之后再讨论数据集资格和诊断模型。
