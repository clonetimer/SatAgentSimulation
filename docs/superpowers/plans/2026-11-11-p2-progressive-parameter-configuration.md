# P2：仿真参数配置渐进式重构

## 目标

普通用户先完成仿真时长和采样间隔即可继续流程；需要修改模型工况时，按物理意义查看常用参数；研究人员仍能进入完整 Schema 参数目录。界面层级不得改变参数值、Schema、TaskSpec 或仿真执行链。

## 三种显示模式

### 1. 仅运行参数
- 仅显示运行时长和输出采样间隔（位于向导配置主步骤）。
- 模型参数表单在视觉上隐藏，但不删除、不重置、不重新生成 state.formData。
- 明确提示所有模型参数仍保留当前模型推荐值。

### 2. 推荐参数（默认）
- 展示 importance != advanced 的 Schema 常用参数。
- 继续按 Schema sections 和物理参数组组织；分组默认折叠，避免一次铺开所有参数。
- 参数说明、Schema 默认值和范围继续按需展开。
- 搜索会检索完整注册字段目录；命中高级字段时自动显示结果并展开所属分组。

### 3. 全部参数
- 展示 Schema 中全部注册参数，包括 importance=advanced 字段。
- 展开参数分组，方便专业用户系统检查完整配置。
- 仍然使用同一份表单数据、同一组字段控件和既有校验流程。

## 交互与状态
- 三种模式由 state.wizard.parameterMode 单一状态驱动。
- 切换模式只改变字段可见性和分组展开状态，不改写任何模型参数值。
- 切换模式会清除分组展开缓存，确保推荐与全部状态一致可预测。
- 搜索输入复用既有 formFieldSearch，不创建第二套过滤逻辑。
- 任一字段修改仍通过既有表单 commit、客户端校验和 TaskSpec 失效机制。
- 运行前正式预检仍是唯一的执行门禁；任何配置修改都必须重新校验。

## 数据完整性约束
- 所有字段继续来自 Capability Registry 派生的 Form Schema。
- 不根据界面层级裁剪或重建 state.formData。
- 不改变默认值、单位、数值范围、枚举、参数类型或字段语义。
- 专业字段仅视觉折叠；导出、预检、TaskSpec 投影和执行仍使用完整配置。

## 验收
- 静态契约：三种模式入口、Schema 字段计数、搜索和说明文案存在。
- Chromium：模式切换后 DOM 字段数保持不变；仅运行模式隐藏表单但不移除字段；推荐模式显示常用参数；全部模式开启高级参数；搜索能筛选字段。
- 回归：原有 Agent refinement、TaskSpec、单次 Basilisk 和实时会话测试不退化。
