# Visual Composer V15 一页速查表

## 最短工作流

```text
图形组装
  ↓
多模块装配 · V15
  ↓
快速开始
  ↓
选 ADCS + Reaction Wheel
  ↓
校验装配
  ↓
生成 Python
  ↓
构建并运行
  ↓
查看运行结果
```

## 什么时候去哪儿

| 我想做什么 | 去哪里 |
|---|---|
| 搭模型 | 图形组装 |
| 跑单个已有能力 | 任务流程 |
| 看模块连接/替换模块 | 多模块装配 · V15 |
| 看完整结果 | 运行与结果 |
| 看一条/几条曲线 | Scope |
| 看末值 | Display |
| 导 CSV/JSON | To Workspace |
| 扫 1–3 个参数 | 快速调参 |
| 比较替换前后 | 与基线对比 |
| 给别人运行 | 导出可运行程序包 |

## 最常用快捷键

```text
Ctrl/Cmd + Z           撤销
Ctrl/Cmd + Shift + Z   重做
Ctrl/Cmd + A           全选
Shift/Ctrl/Cmd + 点击  多选
空白处拖动             框选
方向键                  移动 20 px
Shift + 方向键          移动 5 px
Ctrl/Cmd + C/V/D       复制/粘贴/复制观察器
Esc                     取消当前接线
Delete                  删除可删除的观察器/选择项
```

## 启动

Linux：

```bash
VENV_DIR=/path/to/original-sat/.venv ./scripts/start_local.sh
```

Windows PowerShell：

```powershell
$env:VENV_DIR = "D:\path\to\old-sat\.venv"
.\scripts\start_local_windows.ps1
```

浏览器：

```text
http://127.0.0.1:8000/
```
