## 本轮变化

- 创建页突出对象、校验和运行；模板、保存、重置进入“更多操作”。
- 模型说明和教程按需展开，参数说明聚焦时显示；单位、必填标记和错误保留。
- 事件和输出按需展开，已有事件自动展开，参数错误会揭示所在区域。
- 结果区将报告/诊断等低频操作集中，技术ID仍可在“运行信息”中查看；PASS、完整性和工程假设提示保持可见。
- 曲线选择和时间配置按需展开，归一化/原始数值提示保留，为真实图表让出空间。
- 支持键盘开关、亮暗主题、手机与130%字体。

同一默认整星表单、1366×900：参数表单起点从约999px提前到446px，默认渲染创建页文本从4372字符降到674字符。后者统计整个已渲染创建区域，包含屏幕外文字，**不是首屏字符数或信息删除比例**；折叠内容仍可访问。390px手机宽度下表单起点从约1773px提前到653px，运行按钮保留在首屏。原有474个静态控件ID均保留，默认表单值逐项相同。

浏览器22项检查通过，包括真实API校验、实际Basilisk运行PASS及制品VERIFIED、真实曲线绘制与可视性。1920/1366/768/390宽度、130%字体、亮色主题等7张最终截图已逐张查看。完整仿真源码不在此重复保存，四份候选前端文件及SHA见[manifest](manifest.json)。

## 本机预览

```powershell
.venv\Scripts\python.exe scripts/preview_compact_workbench.py
```

先按[实时验证说明](realtime-review/README.md)用uv安装独立预览依赖。命令复制当前应用和本候选到新的本地预览目录，输出独立回环地址；它不改生产src、现有运行记录或耐久实例。默认监督式运行时用于持续会话；限时会话预览加`--native-runtime in-process`。预览使用独立数据目录，可执行新的本地仿真；Ctrl+C停止自己的预览服务。需要主uv环境及已有原生资源。

## 范围与后续

本轮主要优化创建页和运行结果区，不宣称所有实时页面、实验中心、全部设备或所有交互均已重做。当前生产全套1978项通过记录不授予本候选完整生产资格。后续继续处理实时工作区和复杂配置，再与尚待修复的AI事件生成候选一起安排集成/回归。

原始迭代记录在本地保留：v2帮助条因flex收缩被输入框遮挡，已通过修复布局解决，没有强制点击绕过；构建过程中一次终端编码令新增文案变成问号，已修复，并增加可读标签检查。首版按钮统计误计关闭details中的控件，v2统计改为检查折叠祖先和裁剪范围，旧报告不覆盖。

发布后的格式检查补充清理了HTML的8行行尾空白，并将该HTML的换行统一为LF；元素、属性和非空文本的解析序列完全一致，JS/CSS未变。manifest同时保留原22项浏览器检查对应的应用指纹及清理后的当前候选指纹，不将旧记录改写成另一次原生运行。

设计使用`frontend-design`两遍式流程和`awesome-design-md`中的Linear/IBM参考。采用[Carbon表单的渐进披露](https://www.carbondesignsystem.com/building-blocks/core/patterns/forms)与[Grafana的图表聚焦](https://grafana.com/docs/grafana/latest/visualizations/dashboards/use-dashboards/)，未复制品牌页面。设计取舍见[DESIGN.md](DESIGN.md)。
