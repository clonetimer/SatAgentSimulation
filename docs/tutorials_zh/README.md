## 完全新手最短路线

只想先确认“这个东西到底怎么用”，只做下面 5 课即可：

```text
00 完全新手从这里开始
  ↓
03 ADCS + Reaction Wheel 装配
  ↓
05 Scope / Display
  ↓
06 运行与结果
  ↓
09 导出可运行程序包
```

完成后，你已经掌握 V15 的主工作流。

## 一个重要原则

Visual Composer 的职责划分是：

```text
建模画布          → 搭模型、连线、改参数
Scope / Display    → 模型旁边做少量局部观察
运行与结果         → 看完整曲线、QoI、事件和制品
生成 Python        → 查看/交付确定性可执行程序
```

普通物理模块本身**不负责画曲线**。
