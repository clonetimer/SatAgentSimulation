# P7-C2：实验变体到 Run 证据的精确跳转（2026-11-12）

## 目标
从实验对比表中的指定变体进入对应 Run，读取原始 Run Bundle/遥测/事件/制品证据，在诊断工作区查看证据摘要，并可进入完整曲线视图后返回原实验。

## 行为契约
- 跳转必须使用被点击行的精确 run_id；不根据排序、索引或首条记录推断。
- 仅 GET 读取既有 Run 与其指标、事件、曲线、遥测、制品、数据集、FMEA 和故障追溯。
- 禁止在导航时 POST /runs 或重新执行仿真。
- 诊断摘要仅显示实际返回的证据计数；缺失数据明确显示无/未提供，不推断为零故障。
- 诊断包下载复用既有 /diagnostics/bundle?run_id=... 入口。
- 进入诊断和完整运行详情时保留首次来源工作区；从完整运行详情可返回原实验。
- 编辑任务、载入版本与查看 Run 引用继续隔离。

## 实现
1. 实验比较每行增加“查看运行证据”动作。
2. 精确调用 loadRun(run_id)，载入完成后进入系统诊断。
3. 诊断页显示 Run ID、TaskSpec ID、Task Version、状态、验收和证据覆盖摘要。
4. 提供既有诊断包下载及完整运行曲线入口。
5. 高级工作台挂载共享上下文条，保证实验来源返回链贯通。

## 验收
- 真实 Chromium：实验列表 → 对比 → 指定变体 Run → 诊断摘要 → 完整运行曲线 → 返回实验。
- 明确断言仅读取指定 Run，且没有 POST /runs。
- 验证 Task ID/版本、Run ID、Bundle 和来源引用不串线。
- Agent、单次 Basilisk、原生整星回归保持通过。
