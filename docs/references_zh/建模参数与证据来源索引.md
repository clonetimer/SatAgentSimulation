# 建模、参数与证据来源索引

## 1. 证据等级

| 等级 | 含义 | 允许声明 |
|---|---|---|
| demo | 演示/示例参数 | 功能演示、链路验证 |
| engineering_estimate | 工程估计或公开资料范围 | 工程分析，需披露假设 |
| ground_calibrated | 有地面标定数据和可追溯记录 | 地面标定范围内结论 |
| flight_correlated | 有飞行数据关联和误差报告 | 已关联场景范围内结论 |

本交付未提供新的真实标定或飞行关联数据，不能自动提升证据等级。

## 2. 项目内来源位置

| 能力合同与参数定义 | `src/sat_sim/capabilities/` |

## 3. 使用规则

1. 参数来源不明确时标注“假设”或“待确认”；
2. 示例默认值不得写成真实卫星参数；
3. 代理模型必须在结果和报告中保留代理标识；
4. 故障生效需同时提供注入证据和可观测效果证据；
5. 未建模耦合需显式列入边界，不能由后处理曲线伪造；
6. 外部数据更新后，应记录文件版本、哈希、获取时间和适用范围。
