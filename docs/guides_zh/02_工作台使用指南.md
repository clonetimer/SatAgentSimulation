# 工作台使用指南

## 1. 页面区域

工作台主要分为：

1. **能力树**：按部件、分系统、集成和整星层级浏览 Capability；
2. **Schema 表单**：由 Capability Registry 自动生成字段、枚举、默认值和限制；
3. **自然语言 Agent**：将需求转换为受约束 TaskSpec，并高亮变更字段；
4. **TaskSpec/计划区**：查看 Canonical TaskSpec、校验结果和 ExecutionPlan；
5. **运行与结果区**：查看队列状态、指标、事件、遥测和 Run Bundle。

## 2. 主题设置

右上角可选择：

- 跟随系统；
- 浅色；
- 暗色。

选择保存在浏览器本地，不进入 TaskSpec，也不会影响仿真结果。

## 3. 创建任务的三种方式

### 3.1 表单

适合标准场景。选择能力后填写参数，工作台生成 Canonical TaskSpec。

### 3.2 自然语言

适合快速描述复杂场景。示例：

```text
创建完整六分系统整星仿真，运行300秒；60秒载荷关机并在120秒恢复，120秒通信链路中断并在180秒恢复；输出能量守恒、数据守恒和任务门控评分。
```

Agent 修改字段后，应先查看差异列表，再选择接受或撤销。不要直接执行未经检查的模型草稿。

### 3.3 JSON/YAML TaskSpec

适合专家用户和复现实验。导入后先执行校验和计划预览。

## 4. TaskSpec 生命周期

```text
Draft TaskSpec
  ↓ Schema/语义/能力校验
Canonical TaskSpec
  ↓ 依赖、效果、输出和版本解析
ResolvedSpec
  ↓ 构建受限执行 DAG
ExecutionPlan
  ↓ Worker 执行
Run Bundle
```

## 5. 故障与退化

- 故障可按事件时间注入，部分故障支持恢复；
- 退化当前主要在模型构建时生效；
- 不支持的定时退化会明确拒绝，不会静默改写；
- 目标、作用时间、参数变化和物理效果应在事件与指标中可审计。

## 6. 运行状态

| 状态 | 含义 |
|---|---|
| `QUEUED` | 已进入持久队列 |
| `CLAIMED` | Worker 已认领 |
| `RUNNING` | 正在执行 |
| `CANCEL_REQUESTED` | 已请求合作式取消 |
| `SUCCEEDED` | 执行完成且验证通过 |
| `FAILED` | 执行或验证失败 |
| `CANCELLED` | 已取消 |
| `TIMED_OUT` | 超时终止 |

## 7. Run Bundle 重点文件

```text
input/task_spec.yaml
input/resolved_spec.yaml
input/execution_plan.json
runtime/environment.json
runtime/dependency_versions.json
results/metrics.json
results/events.json
results/telemetry.jsonl
results/summary.json
validation/validation_outcome.json
validation/claim_report.json
bundle_manifest.json
SEALED.json
```

只有密封且哈希验证通过的 Run Bundle 才可作为正式运行证据。

## 8. 结果解释边界

- `mission_success_score` 是确定性门控比例，不是概率；
- 工程估计参数不等同于地面标定或飞行标定；
- Web 曲线用于分析展示，不自动构成校准证据；
- “完整整星”表示当前模型库的六分系统组合能力，不表示认证级数字孪生。

## 9. 软实时会话

设置 `SAT_SIM_INTERACTIVE_ENABLED=1` 后，工作台显示独立的实时会话区域；原任务中心仍是默认入口。实时会话提供暂停/继续、单步、倍速、Schema 指令表单、ACK 时间线和多速率曲线。自然语言只生成候选遥控，确定性校验和人工确认后才能执行；故障/退化命令还要求专门角色。

完整 API、背压、恢复和性能边界见 `11_软实时交互仿真指南.md`。

## 10. 曲线输出选择

仿真配置区和运行结果曲线栏均按“整星 → 分系统 → 部件 → 输出组 → 输出量”组织。默认只展开包含已选项的分支；可按中文名称、技术字段、分系统或部件搜索，并用“仅看已选”快速核对。`adcs.*`、`eps.*` 等命名空间通配符不会作为一个伪参量显示；有限维向量、轮组和热节点模式会展开为可独立勾选的具体叶子字段，无法可靠展开的模式不进入选择器。运行结果最多同时绘制 4 条曲线，取消一条后即可选择其他输出量。
