# Parameter Provenance and Calibration Standard

This project separates model construction from parameter qualification.  A
Basilisk field being mapped correctly does not make the parameter value
engineering-valid by itself.

## Confidence profiles

| Profile | Minimum evidence | Allowed claim |
|---|---|---|
| `demo` | Explicit demo default with unit and owner | Interface, workflow and qualitative demonstrations |
| `engineering_estimate` | Data sheet, document, literature value or traceable engineering estimate with range | Preliminary engineering trade studies |
| `ground_calibrated` | Ground-test dataset, immutable dataset ID, uncertainty and validation metric | Engineering analysis using tested hardware/configuration bounds |
| `flight_correlated` | In-flight telemetry correlation, residuals and operating-range evidence | Mission prediction / in-flight analysis within correlation envelope |

## Required registry fields

Every effective parameter used by a mission profile must have a registry record
with at least:

- `parameter_id`
- `owner`
- `config_path`
- `native_target`
- `value`
- `unit`
- `confidence`
- `source_type`
- `source_ref`
- `uncertainty`
- `validity`
- `calibration`
- `approval_status`

Use `unit = dimensionless` for scale factors.  Do not leave units blank.

## Gate rule

A run can use demo values, but its output must remain marked as demo.  A request
for an engineering, ground-calibrated or flight-correlated profile fails unless
all required parameters meet the requested confidence level.

## Current V16 status

The shipped registry `configs/parameters/demo_parameter_registry_v1.json` covers
the current whole-spacecraft V15/V16 mainline parameter surface.  Its values are
intentionally `demo` confidence, so they cannot qualify engineering or calibrated
claims.

## What V16 does not claim

V16 does not invent calibration data, estimate uncertainty from no evidence, or
turn example default values into engineering parameters.  It only creates the
qualification gate and makes demo/uncalibrated status visible in summaries and
datasets.
