# 旧版退化事件的单位兼容

仅在显式声明 `schema_version: 0.1.0`、退化场景使用旧版 `magnitude` 且未声明 `severity` 或 `unit` 时，保留原有约定：`[0,1]` 表示比例，`(1,100]` 表示百分数，后者除以 100 转为 `severity`。因此旧版 `1` 仍表示比例 1；新输入应使用规范格式并明确比例，避免这种历史歧义。

转换写入 `metadata.legacy_unit_conversions`，保留原值、单位、规则及结果。原始模型响应不变。这是格式兼容的单位换算，不是边界截断：负值和超过 100 的值保持原值，并由验证器拒绝。显式 `severity`、规范版本的事件 `magnitude`、故障事件及声明其他单位的输入均不执行此转换。
