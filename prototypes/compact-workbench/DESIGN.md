# 卫星仿真工作台：精简交互候选

用途：工程师选择卫星/分系统，配置、校验、运行，再读曲线与任务判定。用户明确反馈文字臃肿、操作不简洁。本轮改变信息层级与文案，不更改物理或运行语义；生产耐久实例继续使用原版本。

## 第一遍：设计选择

- 基底：轨道蓝`#0d1d30`，面板`#162b43`，边界`#2a4058`，文字`#eef3fa`，辅助文字`#a2b4c9`，交互蓝`#76a8ff`。保留现有亮色主题与错误/警告/成功语义颜色。
- 字体：本机Segoe UI Variable配Microsoft YaHei，正文13–14px、标题18px、主操作13px；代码与原始数值沿用等宽字体。离线工作台不加载第三方字体。
- 对齐：左对齐，以输入和图表的共同边线组织内容。桌面保持目录/配置/结果三域；小屏纵向堆叠、主操作在首屏。
- 主次：运行是唯一主按钮；校验保持可见；模板、保存、重置归入有名称的“更多操作”。模式选择为短标签分段控件，不与运行按钮竞争。
- 文案：页面名称说任务，不说内部版本；模型说明和操作指南按需展开；参数说明在聚焦时显示，单位、必填标记、校验错误和运行异常始终保留。

```text
目录           当前仿真对象 / 模型说明       校验  运行  更多
搜索对象       配置 | 图形组装 | AI | 任务JSON
对象列表       离线  限时实时  持续实时     运行状态
               关键配置                     指标 / 曲线
               事件 / 输出按需展开           事件 / 证据 / 下载
```

## 第二遍：反默认检查与修订

不采用Linear营销站的大标题、光晕、紫色品牌或大量卡片；借鉴其任务聚焦。保留卫星工程的模型/单位/时间语境，使用安静的输入分组和主要数据区。移除已有装饰渐变和重复说明，避免通过缩小文字伪造简洁。首轮仅优化已能实际验证的创建工作流；未审查的页面不标为全部完成。

## 公开参考与采用理由

- Carbon官方表单规范：相关输入分组、简短标签、随上下文披露次要配置。https://www.carbondesignsystem.com/building-blocks/core/patterns/forms
- Grafana官方仪表盘说明：数据面板聚焦、工具栏和全屏提供上下文操作。https://grafana.com/docs/grafana/latest/visualizations/dashboards/use-dashboards/
- frontend-design的两遍式设计方法与awesome-design-md的Linear/IBM参考作为设计比较资料，不复制品牌样式。猜测的Linear `/docs/issues` 深链404，不作为已读取的页面证据。

## 验证门槛

首屏可见文字和按钮数量与原版同场景比较；不得丢失DOM控件ID、配置值或API行为。验证更多操作、帮助、键盘焦点、主题切换，1920/1366/768/390宽度与130%字体；至少一次真实后端校验、原生运行和结果曲线。截图必须实际查看，未通过项目明确保留，候选不冒充生产已上线。

## 实时工作区后续方案（尚未实施）

沿用上述颜色、字体和左对齐策略，把用户正在进行的任务放到首位：选中会话后，先看到运行状态、仿真时间、漂移、启动／暂停／停止和遥测；会话创建表单作为独立入口，避免始终挤占观测区。桌面以遥测为主栏、遥控为侧栏，手机按状态、遥测、遥控排列。

```text
会话列表       会话名称 / 状态 / 仿真时间       刷新
新建会话       启动  暂停  继续  停止并归档    更多
               遥测对象 / 时间范围              遥控对象
               实际曲线                        指令 / 时刻 / 发送
               事件与回执                      按需配置
```

把原生PID、写入者代际、归档技术细节和恢复覆盖检查归入有明确名称的“运行诊断”；恢复检查不使用内部版本号作为标题。异常、漂移告警、未归档状态及“异常中止后需新建会话”仍在主区可见，不能通过折叠掩盖故障。缩短重复说明，完整工程范围和配置冻结条件保留在帮助中。

第二遍自查：不增加新的装饰卡片，不用更小字体换空间，不将全部内容折叠成难找的菜单；停止、遥控发送及错误反馈保持直接可达。本方案尚未改动实时页源码。当前预览工具无可连接浏览器，后续须取得真实会话、遥控回执及多宽度截图证据后再声明完成。
