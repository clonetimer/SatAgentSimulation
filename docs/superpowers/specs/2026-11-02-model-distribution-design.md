# 微调模型分发设计

用户已选择并要求执行：现有GitHub仓库Release分发LoRA包，ModelScope获取基座，自动准备和启动，使用全新目录验证。此前本机验收和源码推送不等于第三方已获得模型。

方案比较：直接提交权重会扩大Git历史；单独ModelScope仓库需要额外账户和权限；现有GitHub Release适合当前约74MB适配器，基座继续来自ModelScope。采用最后一种，ModelScope镜像不在本次范围。

新增标准库脚本 `scripts/model_release.py`，提供 install/check/serve 三个命令；提交固定发布清单 `configs/models/satagent-v5-release.json`，绑定Release附件与基座逐文件SHA-256和大小。install支持联网和已有制品的离线安装，安全解包到全新缓存，生成当前机器的基座来源清单及安装记录；check检测缺失或篡改；serve复用现有模型服务与全部校验，不修改推理和仿真代码。

发布包完整保留原适配器及训练来源，包括只作哈希追溯、不反序列化的training_args.bin。原元数据中的历史路径不参与定位；加载器明确使用新生成的基座清单和新的适配器目录。另附正式模型卡、基座Apache-2.0许可和固定基座清单。原始权重、训练来源和旧验收包保持原样，不重新训练、不改写69例评分。

验收覆盖：真实本地HTTP下载、离线安装、错误哈希/大小、路径穿越/符号链接/重复或多余ZIP条目、损坏缓存、失败不覆盖已安装文件；从新目录获取实际发布附件、获取或逐字节复制校验过的基座、在兼容CUDA上加载并完成一次真实生成和脚本执行。GPU依赖可复用已核验锁定环境，但应明确披露，不冒充全新依赖安装；无GPU用户使用现有远程模型配置，不提供未经验证的CPU保证。

GitHub上传先形成可审阅制品；用户本轮“执行”已授权该方案的发布和源码推送。若自动审批拒绝，仅报告具体阻断，不绕过。公开制品不包含私有模型服务配置或密钥。
