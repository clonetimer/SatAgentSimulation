# R84-R1 独立噪声与原生 IMU 可观测性：预注册协议

> 预注册日期：2026-11-06（UTC）
> **状态：PREREGISTERED_NOT_EXECUTED。** 本协议必须先于 R84-R1 原生物理运行冻结。不得先运行后改种子、阈值、严重度或分析窗口。

## 1. 科学问题

R84-R0 已证明官方 Basilisk IMU 旁路观察器不改变原有 FSW/RW/spacecraft 物理链，但 0.9° 激励下的三轴最大故障效应约为 \(4.09\times10^{-5}\)、\(9.94\times10^{-6}\)、\(6.52\times10^{-6}\) rad/s，低于 R0 中约 \(10^{-4}\)–\(1.38\times10^{-4}\) rad/s 的噪声残差标准差。

R84-R1 要回答：

1. 当健康与故障工况使用**互不重叠的独立 IMU 噪声种子**时，真实原生陀螺仪观测分布是否仍有可辨识差异？
2. 差异是否依赖目标轮方向、初始姿态、FSW 参考激励幅值和执行机构故障严重度？
3. 在只使用健康校准运行设定阈值时，独立健康控制组的经验误报比例如何？
4. 噪声从 \(5\times10^{-5}\) 增至 \(2\times10^{-4}\) rad/s 时，观测分布重叠如何变化？

本轮是**原生物理可观测性统计试验**，不是训练或验证诊断模型。

## 2. 固定原生物理设计

| 因素 | 冻结取值 |
|---|---|
| Basilisk | 原 R83m 官方 bsk 2.11.0 Wheel，SHA 固定；仅 metadata-only satfix2 兼容标记 |
| 目标反作用轮 | RW0、RW1、RW2 |
| 初始姿态 MRP | (0,0,0)、(0.001,-0.0005,0.0007)、(-0.0008,0.0007,-0.0004) |
| FSW 参考激励 | 0°、0.5°、0.9°，沿目标轮轴 |
| 执行机构容量 | 健康 0.020 N·m；loss50 0.010 N·m；loss75 0.005 N·m |
| IMU 白噪声 \(\sigma\) | 0.00005、0.0001、0.0002 rad/s |
| 随机种子 | 每次唯一运行使用预注册公式生成的独立正整数 |
| 采样与时长 | 0.2 s；6.0 s；每次 31 个样本 |
| 参考调度 | 1.8 s 设置，3.8 s 复位 |
| 物理故障边界 | 原生 scheduler 暂停于 2.4 s；首个故障后样本 2.6 s |

原生链保持：

\`spacecraft + reactionWheelStateEffector + simpleNav + inertial3D + attTrackingError + mrpFeedback + rwMotorTorque\`

官方 \`imuSensor.ImuSensor\` 通过 \`scStateOutMsg\` 连接为旁路观察器。FSW 继续使用 \`simpleNav\`，不得将 IMU 接入控制反馈，不得用 Python/NumPy 后处理噪声替代官方 \`PMatrixGyro\`、\`setAMatrixGyro(0)\` 和 \`RNGSeed\`。

## 3. 独立种子与样本规模

每个完整 6 s 原生 Basilisk 执行才是一个统计单位；同一次运行内的 31 个时间点不能当成 31 个独立样本。健康与故障类别之间不共享 RNG seed；健康校准组与健康误报控制组也使用互不重叠的 seed。

### 主噪声水平：0.0001 rad/s

对每个 \`wheel × initial × reference\` 物理上下文，分别执行：

- 20 次 \`healthy_calibration\`：只用于估计健康中心与阈值；
- 20 次 \`healthy_false_alarm_control\`：只用于独立误报控制；
- 20 次 \`loss50\`；
- 20 次 \`loss75\`。

27 个物理上下文，共 2,160 次主噪声原生执行。

### 噪声敏感性

在 0.00005 和 0.0002 rad/s 两个噪声水平下，每个物理上下文、每种容量状态（healthy/loss50/loss75）分别执行 6 个独立 seed，共 972 次。

### 物理基准

对每个物理上下文额外执行一次 loss50、零陀螺白噪声的原生参考，共 27 次，用于确认 IMU 观察器和噪声不改变真实物理链。healthy/loss75 运行直接对照 SHA 固定的 R83m 原始 54 案例归档。

总计：3,159 个唯一原生运行，另加 1 次固定 seed 确定性回放控制，共 3,160 次执行。

## 4. 预注册种子分配

每个唯一运行的种子使用固定公式：

\`10000000 + cohort_code*1000000 + wheel_index*100000 + initial_index*10000 + reference_index*1000 + noise_index*100 + repetition_index\`

不同 cohort 使用不同 code；健康校准、健康误报控制、loss50、loss75 和两档敏感性数据之间不得复用 seed。运行前和运行后都必须核验 seed 全局唯一。唯一回放控制是唯一允许的重复 seed，并且不得计入独立样本数。

## 5. 仅使用原始 IMU 的统计量

传感器观测文件只含不透明 \`record_id\`、时间戳和三个官方原始陀螺仪通道：

- \`imu.raw_gyro_rad_s_x\`
- \`imu.raw_gyro_rad_s_y\`
- \`imu.raw_gyro_rad_s_z\`

固定窗口（两端均包含）：

- 故障前：0.4–1.6 s，共 7 点；
- 故障后：2.6–3.6 s，共 6 点。

每次运行只从原始陀螺仪计算：

\[
RMS_{3D}=\sqrt{\operatorname{mean}(g_x^2+g_y^2+g_z^2)}
\]

\[
\Delta RMS_{3D}=RMS_{post}-RMS_{pre}
\]

主噪声水平下，以 20 次健康校准运行的 \(\Delta RMS_{3D}\) 中位数为中心，定义单变量偏离分数：

\[
S=\left|\Delta RMS_{3D}-\operatorname{median}(\Delta RMS_{3D,healthy-cal})\right|
\]

固定阈值为健康校准组 20 个 \(S\) 的 nearest-rank 90th percentile。该阈值只应用于独立健康误报控制、loss50 和 loss75；不根据故障结果调参。

预先报告：

- 独立健康误报控制组的经验误报数/比例；
- loss50、loss75 超过健康阈值的数目/比例；
- 各组特征中位数、IQR、最小值、最大值；
- 独立健康与故障分布的 Cliff's delta 和一维 Wasserstein-1 距离；
- 低/高噪声下相同的分布统计，但**不迁移主噪声阈值**。

这些是固定单变量统计探针和分布描述，不是已训练分类器，也不是正式检测器准确率。20 个健康控制样本不足以证明 1% 或更低的误报率；不得作此类资格声明。

## 6. 原生物理 QA 与数据隔离

每次运行必须记录并核验：

1. 真实 C++ \`ReactionWheelData[target].u_max\` 读回；
2. 真实 \`rwOutMsgs[target].u_current\` 不超过对应容量；
3. IMU、FSW、RW 和 spacecraft recorder 的 31 点时间戳完全一致；
4. healthy/loss75 物理通道逐项对照 R83m 原始归档；
5. loss50 物理通道逐项对照同一物理上下文的零噪声原生基准；
6. IMU 噪声和观察器不能改变物理 QA 通道；
7. 保留所有零激励和不可观测负例。

原始 sensor 文件不得出现故障标签、容量状态、轮索引、故障时刻、hub 真值、实际施加力矩或任何 \`QA_ONLY\` 字段。物理 QA 与案例清单分文件保存。时间窗口只用于本次离线研究分析，不作为模型推理特征。

临时研究包络仍为请求力矩不超过 0.020 N·m、轮速不超过 900 rad/s、机体角速率不超过 0.005 rad/s；它们不是飞行安全限值。

## 7. 失败与停止条件

原生 IMU 消息缺失、seed 重复、时间戳错位、C++ 容量读回不一致、实际力矩越界、物理基准不匹配、观察器改变物理链、特征泄漏或研究包络超限，均标记 FAILED 并保留失败证据。不得放宽阈值、删除负例或重复运行直至通过。

## 8. 明确排除

- 不训练任何诊断模型；
- 不访问或生成受保护 ML VAL/TEST/FINAL；
- 不把时间点当独立样本；
- 不声称统计上合格的误报概率；
