## 当前 AI 失败原因

热环境请求实际模型回答中的四个 `rw_max_torque_nm_0` 至 `_3` 均为 **50 N·m**，超过注册表最大值 **0.2 N·m**。独立按相同 JSON Schema 检查确认四个数值边界错误；模型可能混淆了轮力矩与其他轮参数。结构化解码不能保证所有数值范围，服务端正确拒绝并返回 HTTP 422，脚本未进入有效编译／执行。

当前客户端把 422 作为生成失败，既有“一次校验反馈后由模型修正”的逻辑未覆盖此路径。下一步应实现有界、保留原始失败记录的模型纠错，再重新验证；不能放宽物理范围、替换答案或改写原失败。本次检查点尚未实施该修复。
