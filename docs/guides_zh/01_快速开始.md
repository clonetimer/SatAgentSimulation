# 快速开始

## 1. 环境要求

推荐环境：

- 64 位 Python 3.10～3.13；Python 3.10 自动安装 NumPy 2.2.6，Python 3.11～3.13 自动安装 NumPy 2.3.5；
- 64 位 Windows 10/11，或主流 64 位 Linux；
- 本地开发建议至少 16 GB 内存；
- 完整整星和批量任务建议 32 GB 以上内存；
- 物理仿真以 CPU 为主，GPU 主要用于本地/远程大模型 Provider。

源码包已包含 WMM 和 SPICE 运行资产。首次安装需要访问 Python 包索引，或使用单位内部镜像。

## 2. Linux/macOS 安装

在源码包根目录执行：

```bash
./scripts/bootstrap_local.sh
```

等价的手工命令：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade "pip==26.2.1" "setuptools==83.0.0" "wheel==0.46.2"
python -m pip install --find-links third_party/wheels -c constraints.txt -e '.[api,dev]'
python -m sat_sim.agent_cli doctor --require-api --strict-assets
```

## 3. Windows PowerShell 安装

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\bootstrap_windows.ps1
.\scripts\check_api_stack.ps1
```

手工激活环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

## 4. 启动本地工作台

Linux/macOS：

```bash
./scripts/start_local.sh
```

Windows：

```powershell
.\scripts\start_local_windows.ps1
```

浏览器打开：

```text
http://127.0.0.1:8000/
```

本地默认认证模式为 `disabled`，只适合个人计算机或隔离开发环境。对外监听前必须启用 Token 认证和 HTTPS。

## 5. 首次仿真

1. 在左侧搜索并选择 `whole_spacecraft.composite_digital_twin.v1`；
2. 保持默认配置，将仿真时长改为 20 秒；
3. 点击生成/预览 TaskSpec；
4. 检查能力、故障、退化和输出列表；
5. 提交异步运行；
6. 等待状态进入 `SUCCEEDED`；
7. 查看指标、事件、遥测曲线和制品列表。

也可使用自然语言：

```text
创建完整六分系统整星仿真，运行20秒，输出姿态误差、电池状态、温度、载荷数据率和下行数据率。
```

## 6. 命令行自检

```bash
python -m sat_sim.agent_cli version
python -m sat_sim.agent_cli doctor --require-api --strict-assets
python scripts/verify_source_package.py
pytest -q tests/test_web_workbench.py
```

## 7. 停止服务

前台启动时按 `Ctrl+C`。运行结果默认位于：

```text
runs/
```

控制面数据库和临时制品默认位于：

```text
.sat_sim_api/
```


## 8. Windows 环境修复

如启动阶段出现 FastAPI/Starlette 兼容错误，使用：

```powershell
.\scripts\repair_windows_environment.ps1
.\scripts\start_local_windows.ps1
```

该脚本会删除并重建 `.venv`，按 `constraints.txt` 安装经过验证的 API 依赖组合。
