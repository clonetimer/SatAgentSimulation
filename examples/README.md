# Agent examples

The files in this directory serve two purposes:

- legacy `TaskSpec 0.1.0` compatibility templates used by the deterministic template backend;
- canonical `TaskSpec 1.0.0` examples under `agent_requests_v1/` for new integrations.

The public source of truth is Canonical TaskSpec 1.0. Legacy templates are migrated in memory and retained only for compatibility with existing capability adapters.
