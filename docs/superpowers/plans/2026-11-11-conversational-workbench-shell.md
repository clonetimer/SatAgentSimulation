# 对话式工作台外壳收敛

## 本轮调整

- 普通仿真向导、限时实时会话和持续实时会话使用单列主工作区，不再同时展示庞大的左侧功能目录。
- 高级工作台仍保留完整导航；切换到高级工作台后恢复原有布局。
- 向导对话记录采用左右消息气泡；选项卡、参数区、配置摘要和结果区统一宽度与间距。
- 底部步骤操作固定在可视区域，减少长页面中的反复滚动。
- 实时控制台仍复用原有限时/持续会话 DOM、API、遥测和控制器，不复制后端逻辑；在向导中改为聚焦式布局。
- 小屏幕下改为单列，支持减少动态效果偏好。

## 不改变的边界

- 不改变 TaskSpec、Capability Registry、参数值、模型物理语义、Basilisk 执行链、会话生命周期或遥测数据来源。
- 不删除批量实验、目标实验、图形组装、系统诊断、自然语言解析和 TaskSpec 编辑能力。
- 隐藏左侧导航仅作用于普通向导和实时对话工作区；高级工作台及独立专业工作区仍保留原有入口。
