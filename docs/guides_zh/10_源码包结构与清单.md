# 源码包结构与清单

当前源码树应包含生产代码、自动化测试、配置、有效文档和当前工程基线证据，不包含历史报告、重复仿真副本、缓存、字节码或临时任务输出。

```text
sat_agent_platform/
├── configs/             当前集成与运行配置
├── docs/                当前技术文档
├── examples/            可执行 TaskSpec 示例
├── reports/             当前工程基线证据
├── scripts/             维护、验收和治理入口
├── src/                 生产包
├── tests/               自动化测试
├── pyproject.toml
├── requirements*.txt
├── README.md
├── checklist.md
├── spec.md
└── task.md
```

发布身份、必需文档和必需文件由 `src/sat_sim/release_manifest.json` 统一声明，Python 包内容由 `pyproject.toml` 和 `MANIFEST.in` 管理。

洁净源码检查：

```bash
PYTHONDONTWRITEBYTECODE=1 \
  /mnt/PRO6000_disk/Timer/Sat/.venv/bin/python scripts/verify_source_package.py
```

以下内容禁止出现在最终源码树：

- `.pytest_cache/`、`.sat_sim_api/`、`generated_tasks/`、`runs/`
- `__pycache__/`、`*.pyc`、`*.pyo`
- 开发临时脚本、冒烟结果和重复报告
- 已失效的阶段或版本指南
- 带版本试验后缀的当前入口

历史材料保存在项目目录外的 `/mnt/PRO6000_disk/Timer/Sat/archive/`，不参与打包或验收。
