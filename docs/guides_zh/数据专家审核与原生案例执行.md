## 1. 18 案例原生信号门

预检：

```bash
python scripts/run_astrograph_basilisk_signal_gate.py \
  --dry-run \
  --output reports/rw_native_validation \
  --report reports/rw_native_validation_report.json
```

正式运行：

```bash
python scripts/ensure_basilisk_runtime.py --check-only
python scripts/run_astrograph_basilisk_signal_gate.py \
  --output reports/rw_native_validation \
  --report reports/rw_native_validation_report.json
```

正式门要求：

- 18 个子 TaskSpec 全部严格有效；
- 18 个案例全部由 Basilisk 原生能力执行；
- 9 个故障/名义 Pair 全部通过配对物理验证；
- `formal_training_qualified_pair_count == 9`；
- 不允许代理回退。

## 2. 专家审核

技术门通过后，通过以下脚本记录审核：

```bash
python scripts/review_astrograph_dataset_pair.py \
  <dataset_root> \
  <pair_id> \
  APPROVE \
  --reviewer-id <reviewer> \
  --reviewer-type llm_assisted_human \
  --notes "审查结论和依据" \
  --evidence-ref validation/pairs/<pair_id>.json
```

允许的审核方式：

- `human`；
- `llm_assisted_human`。

不允许纯 LLM 自动审批。审核不能覆盖技术门失败或 Basilisk 证据缺失。
