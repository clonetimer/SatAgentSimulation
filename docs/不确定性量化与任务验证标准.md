# UQ Mission Validation Standard

This document defines the V17 uncertainty-quantification boundary for the current satellite simulation package.

## 1. Scope

V17 provides a reproducible uncertainty-propagation harness around the V15 whole-mission coupling path:

```text
ADCS pointing gate
  -> payload data generation
  -> storage
  -> native access / RF / downlink
  -> EPS / thermal / propulsion telemetry
```

It is a demo UQ framework unless supplied with calibrated parameter distributions and independent validation data.

## 2. Qualification levels

| Level | Meaning | Allowed claim |
|---|---|---|
| demo_uq_only | Uses explicit demo uncertainty ranges | software pipeline / sensitivity smoke |
| engineering_uq | Uses documented engineering-estimate distributions | preliminary design uncertainty |
| ground_calibrated_uq | Uses ground-test fitted distributions and validation data | engineering validation support |
| flight_correlated_uq | Uses flight-correlated parameter/posterior data | mission prediction support |

The current `mission_uq_demo_v1` design is `demo_uq_only`.

## 3. Required outputs

Each UQ campaign must emit:

- resolved design file;
- sample table;
- QoI quantiles P5/P50/P95;
- sensitivity screening matrix;
- identifiability status;
- timestep/output-cadence convergence evidence;
- calibration/validation split status;
- explicit `not_claimed` list.

## 4. Non-claims for demo UQ

The demo UQ profile must not claim:

- engineering uncertainty bounds;
- ground-calibrated parameter distributions;
- flight-correlated mission probability;
- validated RF link margin statistics.

## 5. Promotion requirements

To promote from demo UQ to engineering or calibrated UQ, provide:

1. parameter registry entries with non-demo confidence;
2. uncertainty distributions tied to source documents or datasets;
3. calibration and validation dataset manifests;
4. sensitivity and identifiability review;
5. timestep and sampling convergence evidence;
6. independent validation residuals.
