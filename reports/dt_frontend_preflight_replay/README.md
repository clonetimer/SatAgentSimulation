# DT 工作台运行前检查、控制与回放验收

范围为 Windows 上的通用近地小卫星原生整星场景。基线为 PR #246，使用当前工作树前端、真实 Chrome、Basilisk 和本机 `dt-qwen25-coder15-v5` 服务。每格验收独立创建任务或会话。[逐格结果](results.json)记录了运行标识、提交一致性和回放证据。大体积原始截图、遥测与模型响应保存在本机。

## 如何判定

2026-11-24 本机结果为 **15/15**。五个离线整星 Run 均完成封存和场景回放；五个限时会话均完成暂停、单步、继续、自动结束与归档回放；五个持续会话均完成重连、手动停止与归档回放。三种模式各执行一次真实自然语言模型生成。离线自然语言项采用独占模型服务后的复验结果。相关导航、初值和参数保护回归另有 82 项通过。

| 路径 | 实际浏览器操作 | 判据 |
| --- | --- | --- |
| 表单、JSON、场景、自然语言 → 离线 | 设置 30 秒并校验，从检查页返回；确认时长和采样仍在，改为 20 秒，再次校验后运行 | 修改后按钮要求重新校验，模型、参数、事件和输出保留；展开的完整 TaskSpec 与捕获的实际 POST 请求深度相等 |
| 图形 → 离线 | 拖动配置节点，在画布检查已编译参数；重新进入节点，时长由 20 秒改为 30 秒，再返回改为 20 秒 | 检查节点值与先前快照相符；最新编译结果与实际提交深度相等 |
| 全部入口 → 限时或持续实时 | 在会话创建区展开请求，收起后检查已编辑时长，再改回基准值并展开，实际创建 | 比较完整会话请求，含初始化参数、遥测配置与时钟选项。另读原生首帧核对三轴初值 |
| 离线结果 | 从向导结果页进入数字场景；图形入口使用场景导航 | 封存完整性通过；场景来源是本次 Run ID，显示有效姿态与 SEALED 状态 |
| 限时控制及结果 | 暂停、单步、继续，发送安全模式指令，待 20 秒自动结束 | 暂停时仿真时间静止，单步推进 0.5 秒；核对指令回执、物理响应及封存。重选会话，从持久化遥测读取时间窗，用 End 键走到最后一个原始帧 |
| 持续控制及结果 | 刷新后重连原会话，主动停止，展开回放并移动时间滑块 | 全程仅创建一次会话，服务端返回 COMPLETED 和 SEALED；归档 SHA-256 与文件一致，界面末帧序号与历史响应一致 |

自然语言用例检查实际模型身份及候选 TaskSpec，应用候选后再编辑。草稿保持的范围是本次页面内返回或收起检查；持续模式另测运行中刷新后的会话重连。

## 复验

发布前补测了桌面 1440 像素与手机 390 像素宽度的公共导航。任务中心可区分没有已保存任务与筛选无匹配，清除筛选后焦点返回搜索框。帮助页补充了五种入口和任务查找路径。真实 Chrome 的 4 项布局与交互检查通过。

沿用[原生环境与模型服务设置](../dt_next_creation_runtime/README.md)。使用仓库的 uv 环境，设置 Chrome 路径、两个原生浏览器开关、模型地址与名称，并为两类证据指定新目录。一个模型服务串行运行以下命令：

```powershell
uv run --active --no-sync python -m pytest tests/test_p9l4_offline_native_ui_browser.py tests/test_v15_visual_flow_run_browser.py -q
uv run --active --no-sync python -m pytest tests/test_p9f_native_browser.py::test_native_user_created_session_drives_actual_globe_renderer -k "not sidebar and not scene-bounded and not scene-continuous" -q
```

早期实测暴露了离线请求仍在轮询时向导提前进入完成页，以及限时控制请求待处理时按钮可能提前开放的问题。完成页现按实际运行终态和已封存结果更新；限时按钮按待处理状态禁用。验收代码按动作匹配回执，并用一纳秒绝对容差比较原生末帧时间。并发占用同一模型服务产生过一次离线 HTTP 429，该次记录保存在 `.tmp/dt-ux-accept/finite/natural_language`。
