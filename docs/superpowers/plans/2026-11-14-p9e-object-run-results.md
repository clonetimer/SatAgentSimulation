# P9-E：封存 Run 与对象级结果关联

## 目标

在 P9-D 对象树中，选择整星、分系统或单机后，能够查看当前已加载 Run 中真正记录的曲线参量与遥测样本。结果必须来自同一个封存 Run Bundle，并通过完整性校验。

## 设计边界

- 不创建第二套 Run 状态机、结果 API、遥测存储或曲线数据副本。
- 复用现有 `/runs/{run_id}`、`/plots`、`/telemetry` 和 telemetry overview。
- 仅在 `SEALED` 且 `verify_run_bundle().ok` 且运行成功时，将数据标记为可验证结果。
- 结果解析同时核对当前选中的 Run ID，拒绝异步加载造成的旧 Run 结果覆盖。
- 输出与对象的关联必须来自 Capability 输出定义、已审定单机参量字典或现有输出层级映射。
- 整星运行中的分系统遥测不得伪装成单机独立遥测；没有精确单机映射时明确显示无直接关联。
- 展示的末样本值必须标注为已加载样本预览；抽样概览不声称是原始完整遥测。
- 对象结果面板只读，不修改 TaskSpec、仿真参数或已封存数据。

## 实施批次

### P9-E1：Run Bundle 输出关联元数据
- 在既有 plot manifest 中增加输出单位、关联对象 ID、关联层级和关联来源。
- 组件级 Run 只在单机参量字典存在精确字段映射时生成单机对象关联。
- 整星/分系统 Run 只生成分系统或整星级关联。
- 保持原有 series 字段、输出层级和严格请求曲线选择语义。

### P9-E2：对象结果只读视图
- 在数字场景对象配置面板中增加“本次运行结果”分区。
- 按当前选中对象筛选已关联输出，并显示单位、字段名、仿真时间、加载样本末值、关联层级和关联来源。
- 分别处理无 Run、未封存/校验失败、无直接映射、仅有父分系统级遥测、无采样数据等状态。
- 选择整星时显示全部已关联结果；选择分系统时显示本分系统与其下属单机的精确映射；选择单机时只显示精确单机映射。

### P9-E3：验收
- Python：plot manifest 精确单机映射、分系统映射、未映射字段和单位来源。
- JavaScript：整星/分系统/单机过滤、父级遥测不冒充单机、封存与完整性门禁、Run ID 防串线、末样本时间和值。
- Chromium：真实浏览器中选择对象、加载已封存 Run、切换对象并验证结果面板与运行 ID 一致。
- 回归 P9-D、P9-C、P4 结果闭环、有限仿真和浏览器 smoke。

## 验收标准

1. 结果面板引用的 Run ID 与当前结果工作区完全一致。
2. 未封存或完整性校验失败的 Run 不展示为可信对象结果。
3. 单机对象只显示具有精确对象映射的单机结果。
4. 分系统结果不得错误下沉到单机。
5. 每条输出保留原始字段名、单位、关联范围及数据预览来源。
6. 不改变原始遥测、Run Bundle、TaskSpec 和仿真执行状态。
