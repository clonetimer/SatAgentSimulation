# R84-R4 三轴覆盖原生可行性试点

状态：本地 81 个原生工况、同 seed 回放和独立证据审计通过；云端复验待确认。本轮只验证来源与物理可行性，**不计算诊断率**。

上一轮独立队列表明单轴四脉冲只在受损轮与机动轴一致时形成明显的 loss75 信号，非对角故障目标轮几乎没有有效激励。因此，本轮在同一个 54 秒原生 Basilisk 运行中依次对三轴各施加四次交替 ±0.9° 参考脉冲。三种循环轴顺序分别为 0→1→2、1→2→0、2→0→1，避免把目标轮固定放在同一个时间段；目标故障轮和初始姿态分别独立交叉。

预注册配置为 `configs/research/r84r4_triaxis_native_pilot_prereg_v1.json`，SHA-256 `adc6e109e92164f5809ed1183a0747a4d86f7fa88214b86912a1adc35904bafd`，锁定原生源码哈希、噪声、种子公式与 3×3×3×3 的 81 工况矩阵。动力学、执行机构、FSW、官方 ImuSensor 和噪声参数承接 R4 交叉轴源；新增的是三轴参考调度，没有改物理故障注入。轮速观察沿用未标定的 R3B 标称敏感性假设，不视为真实硬件测量。

本地结果：81/81 原生执行通过，每次 271 个原生时间点、136 个观测时间点、24 次原生 FSW 参考设置。三轴参考都在 QA 物理消息出现，目标反作用轮 C++ 权限分别读回 0.020/0.010/0.005 N·m，同 seed 原生回放逐点一致。独立审计逐条校验 21,951 个原生时间点、11,016 个观测时间点、1,944 次参考设置和轮速固定种子回放；与五批旧数据无种子重叠。健康工况在不同名义故障目标轮下物理轨迹一致。全部观测文件与故障真值、实际施加力矩和 hub QA 分离。

原始证据保留在 `reports/local_r84r4_20261107/evidence/r84r4_triaxis_native_pilot_v1/`；四份压缩 JSONL 的哈希在 `r84r4_triaxis_manifest.json`。独立审计收据为同级目录 `r84r4_triaxis_native_pilot_audit.json`。这些证据只证明三轴激励的原生实现可运行、可追溯。每个组合仅 1 个新种子，不能估计健康误报或 loss50/loss75 检出，且轮速仍无设备标定。下一步需冻结新一批互斥健康校准、健康控制和故障种子，并按轴顺序、故障轮和初态分别报告结果；R85 数据集资格另行审查。
