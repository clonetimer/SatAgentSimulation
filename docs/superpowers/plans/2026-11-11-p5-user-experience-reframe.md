# P5 用户体验重构：以实时仿真任务闭环为中心

## 设计决策

P5 不以两套页面外观一致作为目标。验收对象是用户能否低认知负担地完成实时仿真任务。限时实时和持续实时有不同的执行策略、服务端能力、数据采集和安全边界；它们共享用户心智模型，但保留不同的真实控制器和 API。

## 用户任务与成功条件

### 任务 1：开始一次实时仿真
用户需要先知道：
- 当前选择的是限时实时还是持续实时；
- 此模式适合什么任务、何时结束；
- 当前服务是否支持所选对象/模式；
- 哪些参数必须设置，哪些可以使用推荐值；
- 创建会话和启动仿真是两个独立动作。

成功条件：普通用户不必理解 quantum、solver 或原生计算图即可使用推荐设置创建会话；高级参数仍可访问。创建不得自动启动，policy 不支持时说明具体原因。

### 任务 2：判断卫星目前是否正常
用户首先需要：
- 当前会话与连接状态；
- 仿真时间、运行速率和最近遥测新鲜度/缺口；
- 少量有明确物理含义的关键指标；
- 一条默认趋势曲线，能切换分系统/指标；
- 异常时看到可理解的解释与下一步入口。

成功条件：默认先显示“状态与关键指标”，不是原始字段目录；所有值必须来自真实 TM，缺失值显示缺失，绝不以 0 或估算值代替。

### 任务 3：发送遥控并确认结果
用户需要选择控制对象、指令、参数和执行时刻；提交前能看懂影响和时刻；提交后区分排队、已确认、已拒绝、执行失败和执行完成。
成功条件：界面明确区分“已提交”与“已执行”；保留 command ID、sequence、reason code 作为可展开技术证据。

### 任务 4：理解发生了什么
事件和遥控回执需要按时间顺序、状态和影响展示。状态码先转换成用户可读文案，原始码保留在详情中。
成功条件：用户能回答“何时发生、发生了什么、是否影响仿真、下一步做什么”。

### 任务 5：处理长时间运行与异常
持续实时的资源监测、长稳证据、恢复审计和原生参数是重要专业能力，不得删除；它们不应打断普通控制流程。
成功条件：普通控制区简洁，工程诊断可从明确入口展开；系统不自动恢复计算图、不自动重放遥控、不将恢复审计误当成恢复动作。

### 任务 6：离开后继续工作
用户需要知道离开页面不会停止会话；回来后能重新选择活动会话并恢复观察。
成功条件：明确活动会话、离开确认、重新进入入口、数据连接状态和历史/归档状态；导航不偷偷停止运行。

## 信息架构

实时工作区按用户决策顺序组织：
1. **会话与运行状态**：当前会话、服务连接、真实状态、仿真时间、倍速。
2. **运行控制**：按服务端状态可用的启动/暂停/继续/单步/停止归档。
3. **卫星健康概览**：轨道、姿态、能源等关键观测值（只显示实际可用字段）。
4. **遥测趋势**：默认推荐曲线，按系统/目的切换；技术字段目录作为高级选择。
5. **事件与遥控反馈**：人类可读状态 + 原始证据。
6. **新建会话**：默认推荐配置；专家参数、导入参数、服务 policy 原因按需展开。
7. **工程与诊断**：资源监测、长稳证据、恢复审计、持久化历史查询。

## 实施批次（以用户价值为验收）

- P5-UX1：会话状态和创建流程渐进披露。活动会话存在时默认收起创建表单；无会话时默认展开。推荐设置优先，专家配置按需展开。
- P5-UX2：卫星健康概览与遥测可读性。关键指标、物理中文名、单位、数据新鲜度和缺口说明；真实 TM 驱动。
- P5-UX3：事件与遥控反馈可理解性。人类可读状态、指令提交/执行区分、技术证据可展开。
- P5-UX4：持续运行工程诊断渐进披露。长稳、资源、恢复审计保留，移出普通用户主流程。
- P5-UX5：离开/重新进入与异常恢复体验。活动会话重入、断线、失败、归档、数据不完整路径。
- P5-UX6：任务驱动的双模式真实 Chromium 测试、键盘/窄屏可用性和完整 Basilisk/会话生命周期回归。

## 不允许的“体验优化”

- 不能只换按钮文案或统一颜色就宣称 P5 完成。
- 不能隐藏用户完成任务所必需的关键参数或专业诊断能力。
- 不能把技术错误吞掉，不能把 QUEUED 当作执行成功。
- 不能显示假进度、假遥测、估算值或合成健康分数。
- 不能把限时/持续实时合并成一个后端状态机。
- 不能因为页面简洁而删除历史数据、长稳证据、资源监控、恢复审计或安全说明。

## 最终验收场景

1. 首次进入、服务可用/不可用、无会话、有历史会话。
2. 使用推荐设置创建限时会话、持续会话；修改专家参数；导入离线配置并审核。
3. 运行中观察关键指标、曲线、连接断开/重连、遥测缺口。
4. 发送普通遥控与需权限指令，覆盖排队、确认、拒绝、失败、完成。
5. 事件发生、暂停/继续/单步、到时结束、停止并归档。
6. 离开有活动会话的页面并重新进入；验证会话未被意外停止或重放。
7. 持续实时资源异常、长稳证据和恢复审计可访问但不会干扰普通操作。
8. 所有状态、数值、曲线和提示均可追溯至真实服务端状态或 TM/TC 记录。
