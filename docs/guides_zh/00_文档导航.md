- 版本：`0.7.8`
- 当前工作区资格：`IN_PROGRESS`，历史通过声明不继承到本轮修改。
- 历史交付目标：Ubuntu/Linux；本轮尚未复验该平台。

- 本轮开发与局部实测平台：Windows；不能从本地结果推导 Ubuntu 验收通过。

当前方法、证据路径及未完成项见 `docs/functional_completion.md` 与 `reports/final_acceptance_report.md`。

本基线不代表真实反作用轮硬件、硬件标定、地面试验相关性、飞行验证或飞行鉴定。
