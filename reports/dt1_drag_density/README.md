# DT-1 阻力输入密度与来源时刻

在固定面积、常数阻力系数、地球共转大气的工程模型中，用体坐标系的相对速度重算三轴阻力。计算式为 F = −½ ρ Cd A |v| v。动力学优先级为 100，MSIS 输出更新为 97，密度记录器以优先级 101 读取本步动力学开始前发布的消息。新增遥测为 orbit.drag_input_density_kg_m3 和 orbit.drag_density_source_time_s。首帧是初始化，施加阻力与此前发布的密度均为零，时间戳零也用于首次有效的零时刻消息。首帧分析应同时读取仿真时刻。环境密度字段继续描述本步更新后的环境输出。

| 动力学及导出步长 | 总帧数 | 同帧环境密度重算的最大矢量误差 | 前一步环境密度重算的最大矢量误差 |
| --- | ---: | ---: | ---: |
| 2 s | 2701 | 1.544 µN | 1.57 × 10⁻¹⁸ N |
| 1 s | 5401 | 0.772 µN | 1.47 × 10⁻¹⁸ N |

两份既有封存轨迹均为 5400 秒；统计使用正时间帧，首帧另列在 JSON 中。基于 4624c3a7 的候选用官方 Basilisk 2.11.0 按原观测天气和原 TaskSpec 重跑 2 秒步长整轨。两包完整性验证通过，2701 帧的 896732 个原字段值逐一相等。直接读取新增字段重算三轴力，全轨含首帧的最大矢量残差为 1.57 × 10⁻¹⁸ N。1 秒动力学、10 秒输出的单独测试逐帧核对对应时刻的稠密密度样本。关闭阻力时不生成来源字段。整合测试文件共 4 项通过，覆盖四效应组合、整轨、产品入口封存和轮驱动死区联合工况。

运行 audit.py 时传入两份稠密封存包目录；运行 compare.py 时依次传入基线与候选封存包目录。dense_results.json 和 paired_result.json 保存可核对的清单哈希、输入和统计量。此证据验证力与输入的数值、时序一致性。NRLMSISE 密度的独立外部精度、真实器件面积及 Cd 的任务误差预算仍待验证。
