# P7-D：完整用户旅程验收（2026-11-12）

## 目标
从普通用户入口验证仿真工作流端到端连贯性，并覆盖桌面/窄屏、键盘操作、校验失败恢复、运行结果回看和跨工作区上下文。测试中的 API 仿真响应只用于 UI 流程验收；原生物理真实性由独立 Basilisk CI 门禁负责。

## 用户旅程
1. 从默认向导选择正常仿真。
2. 选择已注册对象，选择离线运行。
3. 检查配置摘要并执行服务端 TaskSpec 校验。
4. 提交一次运行，跟踪真实执行状态契约。
5. 读取该 Run 的指标、事件、曲线、遥测、制品和验证结果。
6. 返回配置，确认配置可继续编辑；进入高级工作台，确认唯一结果面板恢复。
7. 窄屏下检查无页面级横向溢出；键盘可聚焦并激活向导选项。

## 异常恢复
- TaskSpec 校验失败时不提交 Run，保留配置和可见错误。
- Run 结果子资源失败时明确显示数据源警告，不以空数据冒充成功。
- 运行读取失败不残留上一 Run 的曲线、指标或事件。
- 实时会话离开确认取消时保持原视图和会话状态；不自动停止/恢复/重放。

## 设计边界
- 继续复用现有 Wizard、TaskSpec、Capability Registry、runSimulation、pollRunExecution、loadRun 和 Run Bundle。
- 不新增第二套执行状态机或复制结果面板。
- 测试 transport fixture 不代表 Basilisk 物理验收；必须保留独立原生整星回归。
