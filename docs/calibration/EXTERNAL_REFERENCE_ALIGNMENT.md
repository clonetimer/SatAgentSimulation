# 外部参考仿真统计量的参数对齐

## 范围与来源

本任务只做 EPS、热稳态和姿态三类统计量的一致性对齐。参考信息来自用户提供的十三份 CSV 的汇总统计；本项目没有获得、读取或重建原始 CSV，也不推测其具体时序。参考本身也是仿真输出，不是真实飞行或硬件数据；此处不构成真实标定、物理覆盖提升或飞行精度声明。

基线：`3bdb3b96ce63f5c5bd197ee3f9a03869f87846cb`。对齐分支：`feat/external-reference-alignment`。本表已填入当前模型实际运行统计；缺失对应输出、统计定义或容差的项目保留“未对齐”。

## 可比性审查与参数决定

### EPS：先建立电气边界，再谈参数

当前 Unified／Composite／原生 EPS 主路的官方 `SimpleBattery` 接收功率节点，给出 W、J 与 SOC；`currentNetPower` 的 current 表示“当前”，不是电流 A。现有路径没有 BCR／放电调节器的端电压、电流限流器或充电导通状态。仓库纯 Python 电池参考模型虽然另有电压、CC/CV 与电流限值，也不能冒充原生整星已有这些功能。

因此本轮不猜测 28 V 等电压，不把 `P_net > 0` 的样本比例解释为 31% 充电占空，也不通过安排开关波形把均值凑成零。满充钳位可能使储能不再增长，但不表示净功率或电流均值为零。Unified 的资源证据范围是功率来源与内部入热，不能借该状态宣称已做原生电池积分守恒审计。

有一个**条件性一致性检查**需要数据持有方澄清：仅当 5／6／7.csv 是相同窗口、相同电压测点、同一列关系，且定义 `I7 = I6 − I5` 时，给定均值将推出 `0.04 − 0.58 = −0.54 A`；同样假设下，差值上界不超过 11.4 A，无法推出 15.8 A。这个结果说明尚不能假定上述关系，**不意味着已发现原始数据错误**。可能是测点、聚合、转换或符号口径不同。

若 31% 指严格零关断情况下的导通样本比例，则 `0.58/0.31 ≈ 1.871 A` 与 1.88 A 平台相容；这只核对摘要关系，不推断任何开关时刻或相位。

### 热：测点与节点尚不等价

当前推荐整星模型有 battery、electronics、payload、adcs、structure、solar_panel、comm、propulsion 八个集总热节点。没有六个轮轴承、四个光源、四个光纤环、两个阻尼器、四个调节器或固放 A/B 的独立温度状态。不能把 ADCS 总温度当作轴承温度，也不能把 electronics／comm 总温度分别改名为调节器／固放测温。

电池五测点和太阳板十测点只适合作为同类集总输出的**待确认包络对照**；需要明确设备、位置及汇总权重，才能谈测点级偏差。电池加热器现有设定点 286 K（12.85 °C）、迟滞宽度 5 K，对应开／关阈值 10.35／15.35 °C；参考平均温度落在迟滞带内，不证明设定点匹配。初温等于参考均值也不证明稳态热平衡。

近稳态均值约束净热收支，不能识别热容量或热时间常数；波动又可能混合控制、环境、测量层伪迹与坏值。因而本轮不调整热质量、比热、导热、发射率或加热器参数来强行贴合摘要，也不新增噪声或热节点。

### 姿态：单位可换算，参考系不能猜

本模型保存刚体真值 `omega_BN_B`，即 B 相对 N 的角速度在 B 系表达，单位 rad/s；另显式换算为 °/s。姿态以 MRP 真值保存，并由官方 `MRP2Euler321` 派生 yaw/pitch/roll，先在弧度中 unwrap，再转为度，同时保留原 wrapped 角。Euler 角速率与机体系角速度不是同一种量；参考 12.csv 尚未声明属于哪种，不能直接算严格逐轴误差。

用户给出的 ±179.3° 是 wrapped 偏航包络。没有参考侧展开后的统计，不能把穿越 ±180° 的跳变算成巨大的姿态误差，也不能从角度范围补出转动轨迹。控制增益和初始姿态／角速度不会为拟合这个未知包络而修改。

## 阶段开发经验

- 统计接入：先保存用户实际提供的摘要与缺失项；1.csv 两处均值不一致、5／6／7.csv 电流边界不明确，均保留为待确认，不自行修补。
- 现值测量：同为“电池”也可能是电流、功率、SOC 或热测点；先核对原生输出单位与节点身份，再计算偏差。没有给电流配猜测电压，也没有把集总温度改名为测点。
- 统计更正：Unified 把未就绪电池容量展示为 1e-12 J，不能仅以容量大于零判断有效；修正统计时保留原始遥测和初版，太阳阵首帧不随电池删除。
- 证据绑定：模板请求与实际展开输入是两份配置；新复现入口在执行前都保存。首轮事后重建的限制如实写入，未把重建配置冒充执行时快照。
- 对齐结论：实际运行成功不等于参考一致性通过；本轮只建立可复核差异，未把外部仿真摘要登记为真实标定，也未因参考摘要不足而新增物理机制。
