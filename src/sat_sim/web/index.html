轨道与整星

机体系主惯量 Ixx/Iyy/Izz（kg·m²）：分别设置 Basilisk Spacecraft.hub.IHubPntBc_B 的对角项。三者必须大于零、满足主惯量三角不等式；只支持对角惯量，不从质量自动估算、也不支持任意惯性积。

ADCS 与反作用轮
磁强计原生安装与校准（展开配置）

测量来自官方 Basilisk Magnetometer.tamDataOutMsg，安装角是 B→S 的 3-2-1 欧拉角；偏置单位为特斯拉 T，比例系数 1 保持原始校准。旧版 Basilisk 2.11 磁强计正常噪声存在随机游走与种子问题，暂不增加未验收的白噪声开关。

IMU 原生测量误差：下列恒定偏置写入 Basilisk ImuSensor；量程填 0 表示保留原生默认，非零时启用对应原生饱和上限。和故障事件注入分开管理。

官方 Basilisk ImuSensor 测量白噪声与项目“故障期间噪声增加”是两种不同机制。以下标准差直接进入官方传感器 PMatrixGyro / PMatrixAccel，并显式设置 A=0（避免 2.11 的陀螺噪声随机游走）。0 为不注入；正值时同一种子、相同环境可复现。

星敏原生正常噪声：单位角秒；0 为关闭，大于 0 使用官方 Basilisk PMatrix 并明确将状态传播设为零（白噪声，非随机游走），区别于故障注入的精度退化。

IMU 原生安装：机体系 B → 平台系 P，按航向、俯仰、横滚（3-2-1）设置；位置为机体系坐标。默认均为 0。

星敏原生安装：机体系 B → 星敏机壳系 C，3-2-1 欧拉角；此处仅配置安装几何，不改变测量噪声。

太阳敏感器独立安装方向：以下机体系 B 法线为官方 Basilisk CoarseSunSensor.nHat_B，不是太阳电池板法线。必须设置单位向量（X²+Y²+Z²=1）。原有默认方向为 (0, 0, −1)，调整会改变真实余弦测量与视场响应，不会改变电池板方向。

太阳敏感器原生测量标定、失真及限幅（展开设置）

这 5 个参数进入官方 Basilisk CoarseSunSensor。传感器先计算余弦与 Kelly 非线性，再加无量纲偏置、乘比例因子，最后进行上下限饱和；它们不控制 EPS 太阳能板，也不表示项目故障注入器的噪声。

轴向为机体系 B 内的单位向量 X²+Y²+Z²=1；每个安装点为 B 系米坐标。不能出现退化的三维控制轴矩阵。切换 3/4 轮构型会重置自定义轴为对应构型的预设方向。

逐轮三维安装位置与轴向（展开配置）
RW1 安装位置 rWB_B 与自旋轴 gsHat_B
RW2 安装位置 rWB_B 与自旋轴 gsHat_B
RW3 安装位置 rWB_B 与自旋轴 gsHat_B
RW4 安装位置 rWB_B 与自旋轴 gsHat_B（仅四轮）

逐轮模式分别写入官方 Basilisk ReactionWheel factory 的 fCoulomb / cViscous：某轮两者都为 0 则该轮无摩擦，至少一轮必须非零；RW4 仅四轮构型有效。该配置在启动前冻结。

反作用轮驱动器电流限制与扭矩常数（展开设置）

电机的实际力矩指令上限为 min(官方 Basilisk RW u_max, 最大电流 Imax × 扭矩常数 Kt)。限幅在调度链路中施加到真实 RW 命令，而不是只修改电流曲线。默认 10 A × 0.02 N·m/A = 0.2 N·m，不改变旧场景。当前不模拟电驱功耗或电池的电机电流负载。

默认全部轮继承上述共享 Imax / Kt。启用后独立计算每只轮的 min(u_max_i, Imax_i × Kt_i)，并据实际施加力矩计算各轮电流和 EPS ADCS 机械轴功估算；仅更改真实驱动命令限幅，不代表官方 Basilisk 已具备详细电机电路模型。

未启用时全部 RW 使用统一 u_max；启用后分别设置实际 Basilisk 电机上限和控制指令限幅，必须大于 0 且不超过 0.2 N·m。RW4 仅适用于四轮构型。

每只 Honeywell HR16 反作用轮的额定动量容量只能选 50/75/100 N·m·s，Basilisk 使用它计算转子惯量 Js；并非运行时限速器或自由连续参数。RW4 仅适用于 4 轮构型。

EPS 电池与太阳电池板

电池板初始法线（机体系 B，单位向量 X²+Y²+Z²=1）。跟踪由项目运动学控制器在 Basilisk 任务内驱动官方太阳板；不包含太阳翼铰链/电机力矩等硬件动力学。

载荷单机
推进分系统 · Basilisk 原生动力学

仅在勾选启用时向整星动态模型添加官方 Basilisk ThrusterDynamicEffector 与 FuelTank。推进电功率估计由项目侧桥接，不是电机硬件级模型。

推进器 T1 安装几何：机体系 B 中的推力方向（单位向量）和相对质心的安装坐标（m）；默认沿 +X 方向。

推进器 T2 安装几何：机体系 B 中的推力方向（单位向量）和相对质心的安装坐标（m）；默认沿 +X 方向。

热控分系统 · 项目热网络

热控为与 Basilisk 仿真任务耦合运行的项目确定性热网络，非官方 Basilisk 原生热模块；温度单位为开尔文。

载荷热容量由质量 × 比热容给出；散热器、加热器均为本项目热网络中的真实调度节点。
