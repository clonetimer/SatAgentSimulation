# P9-F：实时仿真驱动的卫星数字场景

## 目标

将 P9-C Globe.gl 场景从独立演示轨道扩展为可消费两种真实实时仿真会话的只读三维态势视图：

1. 有限/交互式实时仿真（interactive）。
2. 持续实时仿真（continuous）。

两种模式复用同一套 Basilisk 会话、遥测帧和对象结果链，不创建第二个仿真器或第二份物理状态。

## 已核实的数据基础

- 两种实时模式均通过 `/interactive/sessions/{id}/telemetry/{stream}` 或现有 WebSocket 提供 `TelemetryFrame`。
- 帧包含 `session_id`、`stream`、`sequence`、`sim_time_s`、`quality`、`values`。
- Unified Native 遥测包含 `orbit.position_m_x/y/z` 与 `orbit.velocity_m_s_x/y/z`。
- 位置来自 Basilisk 的惯性位置状态；地球固连显示必须结合仿真历元进行坐标转换。
- 当前实时遥测未提供可直接认定为整星本体姿态的四元数。星敏四元数属于传感器坐标关系，不得冒充整星姿态。

## 设计原则

- 场景只消费实时会话遥测，不执行、不推进、不暂停仿真。
- 有限实时与持续实时共用同一个场景帧协议。
- 只接受当前 session、当前 stream、递增 sequence 且质量有效的帧。
- 三轴位置、仿真历元、UTC 时间系统或坐标框架任一缺失时，不显示虚构位置。
- 实时会话激活后，不再用演示轨道覆盖真实遥测；会话无有效帧时显示等待/数据缺口状态。
- 无实时会话时保留 P9-C 演示模式，并明确标注演示数据。
- ECI/J2000 到地固坐标使用 GMST 近似转换，仅用于态势可视化；不宣称导航级地理定位精度。
- 当前无整星姿态四元数输出，卫星模型朝向继续作为示意外观，不标记为真实姿态。
- 组件级三维位置仍需经过审定的资产锚点；对象树选择不产生虚构的单机空间坐标。

## 实施批次

### P9-F1：实时遥测元数据与帧桥接
- 会话状态元数据公开真实仿真历元、时间系统和位置参考框架。
- 有限实时 WebSocket 帧和持续实时轮询帧统一送入 `SatScene.updateRealtimeFrame`。
- 按完整三轴位置字段选择可用遥测流；持续模式在用户选中非轨道流时独立读取轨道流，不改变用户曲线选择。
- session 切换、重连、sequence 回退、数据缺口和会话终止均有显式处理。

### P9-F2：真实轨道位置与地球固连转换
- 由仿真历元 + `sim_time_s` 计算 UTC 时刻。
- 由 Basilisk 惯性位置向量计算 GMST，并转换为地固位置。
- Globe.gl 卫星标记和轨迹由实际遥测帧驱动；演示轨迹与真实轨迹互斥。
- 跟踪/自由观察/全景控制保留，摄像机不抢占用户手动视角。

### P9-F3：会话生命周期与用户体验
- 从有限实时/持续实时切换到场景时保留遥测订阅或轮询。
- 返回控制界面时恢复原会话状态与命令入口，不创建新会话。
- 离开实时场景时明确提示会话仍在运行，不擅自停止仿真。
- 场景展示当前模式、session ID、stream、仿真时间、数据质量和位置来源。
- 没有有效位置数据时不回退到演示轨迹。

### P9-F4：验收
- 单元测试：GMST、ECI→ECEF、日期边界、无效位置、缺失历元、时间系统不支持、质量 GAP/INVALID、乱序帧与 session 串线。
- API 测试：session metadata 的 epoch/frame 与实际 runtime 配置一致。
- Chromium：有限实时和持续实时两种会话均能驱动同一场景；切换视图不停止会话、不丢失帧、不生成重复会话。
- 回归 P9-C、P9-D、P9-E、continuous telemetry、interactive WebSocket、命令控制、session recovery 与 Basilisk 原生闭环。

## 验收边界

1. 场景轨迹由实际 telemetry frame 生成，且保留 session ID、stream ID、sequence 和 sim time 来源。
2. ECI→ECEF 采用明确的 UTC/GMST 近似；状态栏说明该转换只服务可视化。
3. 实时会话没有有效位置字段时，场景显示原因并保持无真实卫星定位，不回退演示位置。
4. 两种实时模式都能接入；continuous 的用户曲线流选择不影响场景轨道流。
5. 场景视图不拥有仿真运行生命周期，不擅自停止或创建会话。
6. 当前没有真实本体姿态四元数，不能将星敏器件四元数用于整星姿态显示。
