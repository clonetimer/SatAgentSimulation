# 本地与普通服务器部署指南

## 1. 部署模式

### 本地开发模式

- API、Web、SQLite 队列和 Worker 在同一台电脑；
- 默认监听 `127.0.0.1`；
- 可使用 `SAT_SIM_AUTH_MODE=disabled`；
- 适合开发、演示和单用户仿真。

### 普通服务器模式

- FastAPI 控制面、SQLite 队列和本地 Worker 部署在同一台 Linux 服务器；
- Nginx 提供 HTTPS；
- 必须启用 Token 认证；
- 运行目录和日志放置在 `/var/lib/sat-sim`。

## 2. Linux 服务器目录

```text
/opt/sat-sim/                 源码和虚拟环境
/etc/sat-sim/                 环境、认证和 Provider 配置
/var/lib/sat-sim/control/     SQLite 队列及控制面制品
/var/lib/sat-sim/runs/        正式 Run Bundle
/var/lib/sat-sim/audit/       API 审计日志
```

## 3. 安装

```bash
sudo useradd --system --home /opt/sat-sim --shell /usr/sbin/nologin sat-sim
sudo mkdir -p /opt/sat-sim /etc/sat-sim /var/lib/sat-sim/{control,runs,audit}
sudo chown -R sat-sim:sat-sim /opt/sat-sim /var/lib/sat-sim
sudo chmod 750 /etc/sat-sim /var/lib/sat-sim
```

将源码复制到 `/opt/sat-sim` 后：

```bash
cd /opt/sat-sim
sudo -u sat-sim python3 -m venv .venv
sudo -u sat-sim .venv/bin/python -m pip install --upgrade "pip==26.2.1" "setuptools==83.0.0" "wheel==0.46.2"
sudo -u sat-sim .venv/bin/python -m pip install -c constraints.txt -e '.[api]'
```

## 4. 配置认证

```bash
sudo cp configs/auth/auth.example.json /etc/sat-sim/auth.json
sudo cp configs/deployment/local.env.example /etc/sat-sim/sat-sim.env
sudo chmod 600 /etc/sat-sim/auth.json /etc/sat-sim/sat-sim.env
```

为每个角色生成独立随机 Token，不要使用示例值：

```bash
python -c 'import secrets; print(secrets.token_urlsafe(48))'
```

把 Token 写入受保护环境文件，或由密钥管理系统注入。认证 JSON 中只保存环境变量名或 SHA-256 摘要。

## 5. systemd

```bash
sudo cp deploy/production/systemd/sat-sim-api.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now sat-sim-api
sudo systemctl status sat-sim-api
```

查看日志：

```bash
journalctl -u sat-sim-api -f
```

## 6. Nginx 和 HTTPS

```bash
sudo cp deploy/production/nginx/sat-sim.conf /etc/nginx/conf.d/sat-sim.conf
sudo nginx -t
sudo systemctl reload nginx
```

必须替换：

- `sim.example.internal`；
- 证书路径；
- 内网 DNS 或正式域名。

## 7. 健康检查

```bash
curl -fsS https://sim.example.internal/health
curl -fsS -H "Authorization: Bearer $SAT_SIM_ADMIN_TOKEN" \
  https://sim.example.internal/health/details
```

## 8. 发布自检

```bash
cd /opt/sat-sim
sudo -u sat-sim .venv/bin/python -m sat_sim.agent_cli doctor \
  --require-api --strict-assets \
  --runs-root /var/lib/sat-sim/runs \
  --artifacts-root /var/lib/sat-sim/control
```
