# 整星电池首帧与同一步功率结算

基于 main `4624c3a7`。在此前的四效应工程样例中，官方电池早于部分负载执行，首帧发布零电荷和零容量，遥测又将容量抬到 1e-12 J。调整后，负载决策读取上一步电池状态，电池在本步全部电气节点写入后积分。电池和加热器电功率的主记录器和各采样组记录器随后取样。初始化时，给控制端提供配置的初始电荷与容量作为上一步反馈；首帧遥测读取官方电池在 t=0 完成本步后的输出。此时净功率已经反映实际节点，积分时间为零。

官方 Basilisk 2.11.0、Windows、步长 0.25 s、时长 6 s、容量 576000 J。三个封存包各有主遥测 25 帧和 1 s 独立记录组 7 帧，重叠时刻的 SOC 一致。每个积分区间均核对电池能量变化与本步原生净功率乘时间间隔，最大绝对差小于 3e-11 J。

| 初始 SOC | 首帧电荷 / J | 首帧净功率 / W | 加热器峰值 / W | 推力峰值 / N | SOC 检查 |
| ---: | ---: | ---: | ---: | ---: | --- |
| 62% | 357120 | 851.1503 | 12 | 2 | PASS |
| 10% | 57600 | 913.1503 | 0 | 0 | PASS |
| 1% | 5760 | 913.1503 | 0 | 0 | WARNING |

三个任务均从 t=0 请求推进，复位安全联锁保持首步禁止；正常电量在下一步获准启动，两组低电量保持禁止。加热设定为 305 K。10% 在原有物理告警区间以外，但低于本任务加热和推进门槛；1% 同时触发低电量警告和负载限制。本次验证覆盖模型内部的初始化和功率反馈时序。
