# 第三阶段：低认知负担配置、曲线选择与任务管理向导

## 目标
将仿真参数、曲线输出和持久任务管理改造成面向任务的规则式步骤。普通用户只需要回答少量问题，专业字段和技术标识按需展开。所有配置仍写入现有 formData / TaskSpec，执行仍使用现有校验、Basilisk、Run Bundle 与 task-center API。

## 参数配置
- 基础配置仅强调仿真时长和采样间隔。
- 两个字段显示中文解释、单位、推荐值/当前值和影响说明。
- 提供短时验证、常规观察、长时分析等时长快捷值；仅当快捷值处于 Schema 的 min/max 范围内时显示。
- 采样间隔提供少量常用快捷值，同样服从 Schema 约束。
- 其他模型参数仍由 Schema 动态生成，放在折叠的高级参数区；不复制字段、不修改默认值。
- 故障事件说明生效时刻、持续时间和幅度；故障项仍只来自当前对象 Schema。

## 曲线选择
- 首屏按注册遥测元数据的 subsystem 分组显示可观测领域卡片，显示已选条数和总条数。
- 每个分组可一键添加/移除该组曲线。
- 展开分组可逐条选择，显示中文名称和物理含义；技术字段只放在次级折叠信息中。
- 保留原始分层搜索作为“按具体遥测量选择”的高级入口。
- 不创建不存在的遥测字段，不根据名称推断实际物理能力；分组和字段完全来自 Schema trace_options。

## 任务管理对话
- 欢迎页“查看历史任务”和左侧任务中心入口统一进入 Wizard 的“任务管理”步骤。
- 搜索、状态筛选、刷新、查看详情、版本历史、运行历史、克隆、编辑、运行和删除复用现有 task-center API/函数。
- 编辑任务后回到向导配置步骤；从向导运行任务后，复用现有运行轮询和 Run Bundle 结果面板。
- 支持将当前已校验或可校验的配置另存为新任务；不覆盖现有任务。
- 删除仍保留原有确认，并明确不会删除已生成 Run Bundle。
- 高级工作台及独立任务中心视图保留作为兼容/高级入口，但普通用户的任务中心导航进入向导。

## 验收
- 普通参数配置不要求用户一次面对所有字段。
- 时长/采样快捷值严格遵守当前 Schema 范围。
- 曲线组卡片只包含当前 Schema 实际注册的 trace_options；逐条选择与原始 plotOptions 双向同步。
- 任务管理步骤能展示任务卡片并操作详情、克隆、编辑、运行、删除和另存当前配置。
- 任务编辑与运行不意外跳回复杂工作台；实时会话的原有离开保护保持不变。
- 浏览器回归无 console/pageerror，真实 Basilisk 有限运行和原 TaskSpec/Run Bundle 契约不变。
