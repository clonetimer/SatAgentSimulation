# UI 功能点与 Playwright 验收清单

本文面向产品验收、回归测试和操作培训，记录卫星仿真工作台当前可见功能。清单中的“自动验收”表示 `scripts/run_ui_feature_playwright.py` 覆盖的浏览器测试；涉及真实 Basilisk 执行、外部模型服务或软实时 Worker 的能力仍应配合对应专项测试。

## 1. 全局框架与显示设置

- [x] 工作台品牌、版本、队列和服务健康状态展示。
- [x] 左侧固定工作台导航和仿真能力目录。
- [x] 浅色、暗色、跟随系统三种主题，选择保存到浏览器本地。
- [x] 小 90%、标准 100%、大 115%、特大 130% 四档界面字号，选择保存到浏览器本地。
- [x] Bearer API Token 会话输入；Token 只保存在当前浏览器会话。
- [x] 忙碌遮罩、成功/警告/错误通知和基础键盘可达性。
- [x] 桌面、窄屏和移动端响应式布局。

自动验收：主题/字号控件可见性、字号立即生效与刷新持久化、桌面和移动端布局。

- [x] 中文名称、故障和能力关键词搜索。
- [x] 层级筛选。
- [x] 默认优先推荐与标准能力。
- [x] 可选择显示兼容、历史和显式能力。

- [x] 显示能力摘要、执行后端、推荐等级和组合调用提示。

自动验收：目录加载、默认活动能力、搜索控件和层级选项存在。

- [x] 表单错误就地提示和汇总。

自动验收：默认 Schema 表单生成、主要操作按钮和表单搜索可用。

## Playwright 执行

```bash
PYTHONPATH=src /home/a/miniconda3/bin/python scripts/run_ui_feature_playwright.py \
  --output-dir reports/ui_playwright_20260804
```

通过标准：所有浏览器检查为 PASS、无未处理 JavaScript 页面错误、无 console error。报告位于 `report.json`，截图位于同一目录的 `screenshots/`。
