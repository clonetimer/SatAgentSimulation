# 12｜常见问题与排查清单

## 1. 浏览器打不开 127.0.0.1:8000

检查启动终端是否还在运行。

再执行：

```bash
curl http://127.0.0.1:8000/health
```

如果 curl 也失败，问题在服务启动，不在浏览器。

---

## 2. doctor 失败

执行：

```bash
python -m sat_sim.agent_cli doctor --require-api --strict-assets
```

根据提示检查：

- 当前 Python 是否来自正确 `.venv`；
- editable install 是否指向 V15；
- 依赖是否安装；
- 资产是否缺失。

---

## 3. Basilisk 不存在

检查：

```bash
python scripts/ensure_basilisk_runtime.py --check-only
```

如果你有 wheel：

```bash
python scripts/ensure_basilisk_runtime.py --wheel /path/to/bsk-2.11.0.whl
```

注意：不是所有 source-native Capability 都必须依赖 Basilisk，但 Basilisk 专项能力需要它。

---

## 4. 模块拖不上去

常见原因：

- interface 不兼容；
- payload schema 不兼容；
- unit 不兼容；
- timing 不兼容；
- allow-list 不允许；
- 这个 slot 不是 replaceable；
- 父模型不拥有该运行时 slot。

先打开“仅兼容模块”筛选。

---

## 5. 端口连不上

检查：

- output → input 方向；
- 数据类型；
- source/target port 所属模块；
- fan-in/fan-out；
- binding 是否已经存在；
- feedback policy。

不要通过手改 JSON 强行绕过校验。

---

## 6. 生成 Python 按钮提示代码过期

如果你修改了：

- 参数；
- 模块选择；
- 物理连接；

这是正常的，需要重新生成。

如果只是移动/对齐节点，V15 不应该令代码过期。

---

## 7. Scope 没有数据

检查：

1. 是否完成过一次 Run；
2. probe 是否接 output；
3. 该信号是否被 recorder 记录；
4. sourceNode/sourcePort 是否匹配；
5. Run Bundle 中是否存在对应 telemetry。

---

## 8. To Workspace 导不出

只有 `To Workspace` observer 能调用数据导出。

并且必须：

- 已完成一次运行；
- observer 已接合法 output；
- 该 output 已解析到 telemetry。

---

## 9. Run 是 SUCCEEDED，但 Validation 是 INCONCLUSIVE

这通常不是程序失败。

可能是：

- 仿真时长过短；
- 验证窗口不足；
- 某项判据没有足够证据。

先看 Execution，再看 Validation 原因。

---

## 10. 导出的程序包在另一台机器跑不了

程序包不包含整个 runtime。

另一台机器仍需：

- 合适的 Python；
- SAT 包；
- 需要的依赖；
- Basilisk（如果该 Capability 需要）。

---

## 11. Windows 下 run.sh Permission / 无法执行

Windows 使用：

```bat
run.bat
```

Linux/macOS 推荐：

```bash
bash run.sh
```

不要依赖 ZIP 解压后保留 executable bit。

---

## 12. 不知道问题在哪时的固定排查顺序

```text
1. doctor
2. /health
3. 画布校验
4. Execution status
5. Validation / Events
6. telemetry 是否存在
7. Run Bundle artifacts
8. 对应专项 pytest
```

推荐专项测试：

```bash
pytest -q \
  tests/test_visual_graph.py \
  tests/test_assembly_graph.py \
  tests/test_visual_diagnostics.py \
  tests/test_visual_results.py \
  tests/test_visual_tuning.py \
  tests/test_web_workbench.py
```
