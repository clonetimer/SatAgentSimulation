# 四效应整星 Run 的四项物理检查

在主干 `4624c3a7` 的验证器上增加原生四元数读入。官方 Basilisk 2.11.0 运行相同的 30 s TaskSpec，步长 1 s，每 10 s 采样。此前封存包和修复后的包均通过完整性检查，两份遥测的 SHA-256 相同。原有检查阈值沿用。

| 检查 | 查明的原因和结果 |
| --- | --- |
| 四元数模长 | 旧检查器仅搜索标量模长。新检查器对同帧有效的四个姿态真值分量直接求模，4 帧全部通过。采样记录缺分量、真值无效、非有限分量或模长越界均有回归用例。这一结果覆盖遥测表示的内部一致性。 |
| 轨道高度 | 原生遥测给出地心位置和半径，通用检查器要求高度。以本包 GGM03S 参考半径 6378136.3 m 独立重算，4 帧球面高度在 271857.64 至 271863.70 m 之间，位于原检查的 100 至 3000 km 区间。产品检查仍为未评估。需先明确所用基准面，椭球大地高需单独处理。 |
| 推进剂单调性 | 本次 TaskSpec 关闭推进，输入中虽有初始推进剂参数，遥测中没有剩余质量时序。该工况保留未评估。开启推进时应使用同一贮箱跨帧的实际质量记录验收。 |
| 数据守恒 | 通用检查读取守恒残差。原生链提供存储量及采样点速率乘采样间隔的位数。10 至 20 s 存储量从 2500 万增至 4750 万 bit，末端记录的生成和下传均为零。需在动力学步长记录实际接收入库、下传和溢出等收支，按同一时间窗核算。 |

运行 `python audit.py <封存包目录>` 可重算逐帧数值。审计依赖对应产品代码的 `src` 目录及其 Python 依赖。旧包见 [before.json](before.json)，新包见 [after.json](after.json)。

## 球面高度和推进剂质量的后续实测

上表描述首次复核。现整星运行时从已校验的 GGM03S 文件头读取模型参考半径，遥测给出地心距离减该半径的球面高度，封存摘要保存高度定义、文件身份和参考半径。原有 LEO 范围检查沿用 100–3000 km。旧 J2 配置继续省略该字段。该指标用于模型内部的轨道范围检查，大地高和地形净空需要各自的参考面。

从[固定四效应 TaskSpec](https://github.com/clonetimer/SatAgentSimulation/blob/27938e3/reports/dt_storage_balance/task.json)生成 30 s 的四个封存 Run。对照组关闭推进，0.5 s 步长。另三组设置相同的 5 s 起始时刻、4 s 指令时长并启用推进。每步采样，官方 Basilisk 2.11.0。逐帧以输出位置三分量求范数再减 6378136.3 m，共 484 帧，与产品字段最大相差 9.32e-10 m 以内。关闭推进时，质量检查保留未评估。三个点火工况均观测到 2 N 峰值，实际贮箱质量非负且单调下降。

| 步长 / s | 采样推力的梯形积分 / N·s | 贮箱消耗 / g |
| ---: | ---: | ---: |
| 0.5 | 8.0 | 4.24882 |
| 0.25 | 8.0 | 4.16384 |
| 0.125 | 8.0 | 4.12135 |

相邻两档耗量差分别为 0.08498 g 和 0.04249 g。质量单调性在三个步长均通过，绝对耗量的准确性仍需针对脉冲边沿的独立时间/流量对照及任务容差。另用独立构造的输入确认 99,999 m 高度和上升的贮箱质量均触发失败。复现时按四效应 TaskSpec 的空间天气夹具配置资产环境，在本目录执行 `python altitude_fuel.py <TaskSpec路径> <新输出目录>`。[逐工况结果](altitude_fuel.json)

## 质量流率与贮箱状态的边沿复核

对相邻两帧，分别从贮箱状态差得出消耗量，从两端质量流率的梯形积分得出第二个估计。三个原始工况的稳态段逐步差值均小于 6e-17 kg。指令与步长对齐时，点火步实际消耗约为满流量一步消耗的 5/6，关机步约为 1/2。端点梯形法对两个边沿均计 1/2。因此这三例的额外耗量全部定位在点火所在步，数值为平台段流率乘以步长的 1/3。平台段总流率为 0.001019716213 kg/s。

根据三个原始工况，在运行留出工况前固定整步矩形脉冲的预测式：总耗量 = 平台段流率 × (指令时长 + 步长/3)。下表列出随后进行的三个独立原生运行。

| 留出工况 | 指令时长 / s | 步长 / s | 贮箱消耗 / g | 相对端点流率积分的差 / g |
| --- | ---: | ---: | ---: | ---: |
| 再减半步长 | 4 | 0.0625 | 4.10011 | 0.02124 |
| 加倍时长 | 8 | 0.25 | 8.24271 | 0.08498 |
| 非整步关机 | 4.125 | 0.25 | 4.29131 | 0.21244 |

前两例的实测与固定预测之差均小于 1e-12 kg。第三例关机所在步的有效流量权重变为 1，说明该预测式有相位适用条件。不要用单一常数校正所有任务的贮箱质量。完整的三组原始包、三组新包均通过完整性验证。复现命令为 `python burn_edges.py <TaskSpec> <altitude_fuel.py输出目录> <新目录>`。[逐边沿时间、质量流率与状态差](burn_edges.json)

官方 2.11.0 实现由贮箱调用喷推器的状态导数贡献，流率使用当前推力因子、比冲及衰减因子；经典 RK4 的四个阶段权重为 1/6、1/3、1/3、1/6。这里的 5/6 和 1/2 来自封存状态差反算。本试验记录的是积分端点，各内部子阶段的调用次序及推力因子仍需直接观测才能进一步归因。[贮箱源码](https://github.com/AVSLab/basilisk/blob/v2.11.0/src/simulation/dynamics/FuelTank/fuelTank.cpp) · [喷推器源码](https://github.com/AVSLab/basilisk/blob/v2.11.0/src/simulation/dynamics/Thrusters/thrusterDynamicEffector/thrusterDynamicEffector.cpp) · [RK4 系数](https://github.com/AVSLab/basilisk/blob/v2.11.0/src/simulation/dynamics/_GeneralModuleFiles/svIntegratorRK4.cpp)
