# 工作台使用指南

## 1. 普通用户：规则驱动仿真向导

首次打开工作台默认进入“开始仿真”。这是固定规则驱动的选择向导，不是大语言模型聊天：

1. 选择“运行正常仿真”或“注入故障并仿真”；也可以直接进入历史任务、运行对比或高级工作台。
2. 选择对象范围（整星、分系统、部件），再从当前已注册且可配置的对象中选择模型。
3. 故障仿真只显示该对象 Schema 中实际注册的故障模板；如果没有可用故障，向导会明确提示，不会虚构选项。
4. 确认仿真时长和采样间隔。其他专业参数、故障作用时间和输出量可进入高级工作台编辑。
5. 检查配置摘要并执行正式校验。只有 TaskSpec 与执行计划校验通过、且校验后配置没有变化，才允许提交运行。
6. 运行后进入原有结果面板；历史任务和运行比较分别使用既有任务中心、运行中心。

向导的“上一步”和“重新开始”只重置向导流程，不删除已保存任务、历史运行或 Run Bundle。切换到高级工作台也不会创建另一套仿真执行链。

## 2. 高级工作台：完成一次仿真

日常使用不需要先理解 TaskSpec、ExecutionPlan 或 Run Bundle 等内部概念。按工作台首页的三步引导操作即可：

1. **选择仿真对象**：从左侧选择整星、分系统或部件。初次体验建议先使用整星或一个熟悉的分系统。
2. **配置运行条件**：先修改仿真时长和采样间隔；需要研究故障时，再添加故障事件并设置开始、结束时间。默认输出可先保留。
3. **校验并运行**：点击“校验配置”检查参数和能力兼容性。校验通过后点击“运行仿真”，等待任务完成，再查看关键指标、事件和曲线。

“校验配置”只检查配置，不会启动仿真。环境预检通过也不代表某个具体场景已经运行成功；最终以该次运行的结果和验证状态为准。

## 3. 页面区域

- **仿真对象目录**：按整星、分系统和部件查找模型，可使用搜索和层级筛选。
- **参数配置**：先显示常用参数；需要时打开“显示专业参数”。优先依据字段旁的中文说明、单位和约束设置参数。
- **事件配置**：添加故障、退化或运行约束，明确作用对象和生效时间。系统不支持的事件形式会明确拒绝，不会静默改写。
- **运行与结果**：跟踪任务状态，查看摘要指标、事件、遥测曲线、验证结论和可下载文件。
- **任务中心 / 实验中心 / 目标实验**：分别管理已保存任务、参数扫描实验和多轮目标驱动实验。

## 4. 三种创建方式

### 3.1 参数表单（推荐日常使用）

适合标准场景。先选择能力，再填写参数、事件和输出。初次使用保持默认输出即可；参数说明和单位以表单显示为准。

### 3.2 自然语言

适合快速描述复杂场景。示例：

```text
创建完整六分系统整星仿真，运行300秒；60秒载荷关机并在120秒恢复，120秒通信链路中断并在180秒恢复；输出能量守恒、数据守恒和任务门控评分。
```

Agent 生成配置后，先检查变更列表，再接受或撤销。不要直接运行未经检查的草稿。

### 3.3 JSON/YAML（专家模式）

适合批量生成、版本管理和严格复现实验。导入后先校验，再执行。

## 5. 图形组装与观察器

Visual Composer 适合需要明确查看模块连接关系的用户。普通模块负责物理建模；Scope、Display 和 To Workspace 是只读观察器，不会改变物理求解链。

- **Scope**：查看运行结束后已记录信号的时间序列，不是实时示波器。
- **Display**：查看最近一次运行中已记录信号的末值。
- **To Workspace**：导出 Run Bundle 中已记录的遥测为 CSV/JSON；不会自动补录未记录的信号。

## 6. 查看结果

建议按以下顺序阅读：

1. 先看运行状态和验证结论；
2. 再看关键指标及其单位；
3. 查看事件时间线，确认故障是否在预期时间生效；
4. 查看遥测曲线，检查关键物理量变化；
5. 最后按需下载原始数据、报告和运行证据。

曲线选择按“整星 → 分系统 → 部件 → 输出组 → 输出量”组织。可搜索中文名称或技术字段。结果界面同时绘制曲线数量有限，取消已选曲线后可继续选择其他量。曲线只反映该次运行实际记录的数据。

## 7. 历史任务与实验

- 保存任务用于复用仿真配置；
- 每次运行会生成独立运行记录，不应把旧运行结果当作新运行结果；
- 参数扫描用于比较有限候选值；
- 目标实验用于在明确的参数白名单、成功条件和累计预算下开展多轮实验。

在“运行与结果”面板选中一条运行后，可直接点击顶部的“复用此配置”，将该次运行保存的配置复制到新建表单。它不会自动启动仿真，也不会改写历史记录。复用后，仍应检查仿真对象、时长、初始条件、故障事件和输出量，再校验并提交新的运行。

需要比较两次运行时，进入“运行中心”，选择两次同模型的已完成运行，再点击“比较选中的 2 次运行”。系统比较各自实际记录的指标和共同遥测；不同时间戳不会被插值后伪装成逐点严格配对。

## 8. 运行状态

| 状态 | 含义 |
|---|---|
| `QUEUED` | 已进入等待队列 |
| `CLAIMED` | 执行工作进程已接手 |
| `RUNNING` | 正在执行 |
| `CANCEL_REQUESTED` | 已请求协作式取消 |
| `SUCCEEDED` | 执行完成且验证通过 |
| `FAILED` | 执行或验证失败 |
| `CANCELLED` | 已取消 |
| `TIMED_OUT` | 超时终止 |

## 9. 结果与证据边界

- `mission_success_score` 是确定性门控比例，不是概率。
- 工程估计参数不等同于地面标定或飞行标定。
- Web 曲线用于分析展示，不自动构成校准证据。
- “完整整星”表示当前模型库的六分系统组合能力，不表示认证级数字孪生。
- 只有密封且哈希验证通过的运行包，才能作为正式运行证据。

## 10. 软实时与持续仿真

软实时会话和持续卫星仿真是独立于普通有限时长仿真的高级工作流。它们可能要求单独启用服务配置、权限和运行环境。自然语言遥控只生成候选指令；确定性校验和人工确认后才能执行。不要将普通任务的取消、刷新或重启理解为整星物理状态可跨进程续算。

## 11. 主题与界面设置

右上角可选择跟随系统、浅色或暗色主题，也可调整字体显示大小。这些设置只影响当前浏览器界面，不改变仿真配置和结果。

## 13. 普通用户：运行方式与完整操作闭环

选择仿真对象后，向导会继续询问运行方式：

- **离线仿真**：设置运行时长和采样间隔；“更多仿真参数”展开完整注册参数；“故障与事件”编辑事件类型、生效时间和幅度；“结果指标与曲线”选择 QoI 和遥测输出。完成校验后提交运行，结果概览、曲线、事件和制品在当前向导中显示。
- **限时实时仿真**：创建限时实时会话后，可启动、暂停、单步推进、调整倍速和停止；实时遥测曲线、事件与遥控回执在同一工作区展示。
- **持续实时仿真**：创建持续整星会话后手动启动，可持续观察遥测和运行状态，并在结束时停止并归档。

实时模式是否可用由当前服务端能力目录决定。当前服务不支持的模式会显示原因并禁用，不会自动切换到另一种运行方式。当前注册策略仅对受支持的原生整星能力开放实时入口；分系统/部件仍可使用离线仿真。

实时控制台中的“返回仿真向导”只离开当前控制界面，不会自动停止仍在运行的会话。离开前会提示会话状态；需要结束仿真时请先使用停止/停止并归档。

高级工作台保留完整图形组装、自然语言和 TaskSpec 编辑能力。普通用户的参数表单、事件和输出控件会在两种工作区之间移动复用，不会生成两份配置。
