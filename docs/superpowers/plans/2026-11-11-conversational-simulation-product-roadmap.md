# SatAgentSimulation 对话式仿真工作台产品级改造方案

## 产品目标

将普通用户的仿真工作流程收敛为一个连续、可理解、可返回的对话式工作区。对话式指引是交互外壳，不替代真实配置、TaskSpec、Capability Registry、仿真 API 或 Basilisk 执行链。

## 设计原则

1. 单一主流程：普通用户不需要在向导、任务中心、结果页之间反复切换。
2. 渐进披露：先展示完成当前任务所需的信息；专业字段、原始遥测目录和诊断细节按需展开。
3. 规则驱动：模型、故障、参数、实时能力和输出选项均从现有 Registry、Schema、服务端 policy 和实际返回数据生成。
4. 透明可追溯：显示单位、推荐值、校验状态、任务/运行 ID、事件时间和数据来源；未知/缺失不补造。
5. 执行链复用：只移动和呈现现有 DOM/控制器，不复制 API，不创建平行状态机或虚构结果。
6. 专业能力不缩水：自然语言、TaskSpec、批量实验、目标实验、图形建模、运行对比、日志和诊断继续可用。
7. 实时安全：离开活动实时会话前明确提示；不自动停止、不自动恢复、不重放遥控指令。

## 阶段路线

### P0 — 基线与回归修复
- 复核 PR #113/#114 依赖关系与失败工作流。
- 将浏览器测试的高级工作台入口改为真实可见的“高级工作台”按钮；实时控制台返回后再进入高级模式。
- 对每个失败工作流读取实际失败断言，修复产品问题而非放宽断言。
- 验收：原生 Basilisk、单次有限仿真、实时控制台、Agent 输入/运行一致性全部通过。

### P1 — 对话式主界面
- 普通向导与两类实时会话采用单列聚焦布局；高级工作台恢复工程导航。
- 增加清晰的四步进度：任务目标 → 仿真对象 → 运行方式 → 配置与结果。
- 对话消息、选项、步骤按钮、通知和窄屏布局统一。
- 验收：每一步有明确当前位置、返回和重置；桌面/窄屏无横向溢出；键盘焦点可见。

### P2 — 低认知负担配置
- [x] 三层参数显示模式：仅运行参数 / 推荐参数 / 全部参数。
- [x] 推荐模式按 Schema importance 展示常用字段，专业字段默认折叠；搜索可命中完整目录。
- [x] 全部模式展开高级字段和物理参数分组；仅运行模式视觉隐藏表单但保留完整 state.formData。
- [x] 参数默认值在说明中明确标为模型推荐值；模式切换不改写任何参数。
- 必要配置只保留时长、采样间隔等运行级参数。
- 参数解释默认简洁，推荐值和常用预设优先；模型专用参数按物理意义分组并折叠。
- 故障事件采用“选择事件 → 编辑触发时间/持续时间/幅度 → 摘要确认”流程。
- 参数变化立即使旧校验失效；只有最新配置校验通过才可运行。
- 验收：不改默认物理参数；无效参数阻断校验/运行；回退不丢失有效表单状态。

### P3 — 观测指标与曲线选择
- [x] 将 QoI 结果指标与时序曲线拆成两个独立选择区，分别写入 outputs.qoi 与 outputs.plots。
- [x] 根据当前 Schema 的 summary_options / trace_options 动态生成观测目的标签和可选项；无注册字段不显示。
- [x] 按观测目的过滤、按分系统分组曲线；支持整组添加/移除、单条选择和技术字段按需展开。
- [x] 增加跨指标/曲线搜索、匹配数量提示和从 Schema default_form.outputs 恢复推荐组合。
- 先按用户观测目的与分系统分组展示推荐曲线，显示中文含义、单位和已选数量。
- 一键添加/移除整组；原始技术字段目录留在高级入口。
- 明确曲线选择会影响记录的数据量；只展示 Schema/注册目录真实存在的字段。
- 验收：选项完整性与 Schema 一致；没有伪造通道；选择结果准确写回原表单并触发重新校验。
