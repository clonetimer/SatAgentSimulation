## #202 独立复现带来的计划调整

1. **初始条件进入任务契约。** 原基线三轴角速度为 `[0.01, -0.004, 0.002] rad/s`。[#224](https://github.com/clonetimer/SatAgentSimulation/pull/224) 的精确 HEAD `5f403b5589670659c1e18520959d0ee349617d88` 已复验默认、旧配置和自定义 `[-0.003, 0, 0.006] rad/s` 的 Basilisk 首帧；向导→服务端与服务端→原生首帧由两个云端作业用同一组字段和值核对。该 PR 已转为可审查、尚未合并；因此主干状态不能写成「可配置初值已交付」。后续合并时应核查实际 main SHA 的默认兼容、旧配置和自定义首帧回归。
2. **电池热侧先校准问题定义。** 请参考方确认：五测点各自的物理位置与传感器/计算量身份，电池及相邻节点安装、接触热阻、导热路径、表面光热参数、受照/遮挡关系、加热器控制与采样时间/聚合窗口。建立原始列→模型节点→单位→坐标/时间→比较统计的逐项映射。未确认前仅报告差异，不用调参制造「通过」。
3. **外部参考与任务验收分层。** #202 的温度差异和三轴峰值差异是模型间对齐发现，不是硬件误差。冻结容差保持温度均值 ±0.5 °C、标准差 ±0.15 °C、角速度峰值 ±10% 等原约定；对于缺少稳态窗口、原始时序和测点映射的指标标记不可判定。角速度初值差异应先按同初值重跑，随后再分析动力学残差。
